# 游戏端：露娜塔下补刀练习

这是游戏机本地的独立练习模式。无需教练端、配对码或模型；不会发出攻击指令。正式对局、观战和不带有效自身 GSI 的画面不启用。

## 开一轮练习

1. 在游戏端展开 **本机练习：正补、反补、塔下垫刀**，选你与目标的距离，点 **开始本机练习**。不用点双机的“连接”。首次会配置本机 GSI；若提示重启，在 Steam 的 Dota 启动选项加入 `-gamestateintegration`，完全退出并重开 Dota。
2. 打开 **英雄 → 露娜 → 试玩**，用默认血条、窗口或无边框。保持一级空装（TP 可以）、白天、前 7 分半；在试玩面板打开防御塔和小兵。面朝目标、站在所选攻击距离内，不开自动攻击或伤害增益。不满足练习条件时，游戏端不会画框。
3. 练塔刀时尽量让己方一塔单独打目标。看到**橙色「垫 1 刀」**，自己点一次；**蓝色「等塔」**时不要多打；**金色「出手 · 塔后收」**表示现在发出的弹道预计会在塔弹之后收尾，不是要等塔弹落地才点。**青色**是己方兵可尝试反补。血条消失或切出游戏，标记撤掉。

**塔还没开火的时候**，展开「按当前血量试算」，输入兵种、当前血量、离第一发塔弹**命中**还有多少秒。这个工具不用启动采集，在主菜单也能用，输入值不会冒充屏幕检测结果。例：中距离、近战兵 150 HP、首发塔弹 1.4 秒后命中 → **垫 1 刀，吃塔 1 下，收尾**；改成 0.4 秒则没有稳妥方案。

## 提醒如何判断

- 游戏机用 Windows.Graphics.Capture 获取 Dota 客户区，在未编码 NV12 像素上找普通兵形状的红/绿血条。连续帧跟踪其填充长度、位置；匹配冲突、长时间没新帧、Dota 失焦或 GSI 不再有效时不保留旧提示。
- 看到同一只敌兵两次掉血，伤害和间隔都符合一塔时，才估计兵种和下一次塔弹命中。**不是**从游戏内读到了塔的攻击目标，也没有逐颗识别飞行中的弹道。多只兵同时像在吃塔伤、突然混入其他伤害、塔换目标或节奏中断时宁可漏报。普通补刀在兵种不明时，按近战兵、远程兵两种上限都能收才提示。
- 算法比较剩余血量区间、英雄和塔的伤害浮动、回血、攻击前摇与弹道合计时间、普攻间隔。优先找不用垫的窗口，其次尝试 1–4 刀；若最不利伤害结果可能让塔打死兵，或者第二次普攻赶不上，不报确定方案。不会估算走位、转身、高低坡丢失、其他英雄技能或多路集火。

## 本机核验（2026-11-18，Dota build 6976）

分别验证了以下三件事，不能当作自然对线的成功率：

| 验证途径 | 结果 |
|---|---|
| 官方 `hero_demo_main`，玩家视角 | 进入了一级露娜试玩，收到 `matchid=0` 的玩家 GSI；从 1920×1080 实际窗口采帧。例：同一张画面上读到两根满血友方兵条，宽度均为 80 像素。另以真实回放 PNG 复核了一根敌方残血条，读出 5/78 像素。 |
| 独立的本地 Dota 引擎，受控的一塔、露娜和普通兵 | 引擎报告露娜攻击间隔 1.371 秒、天辉中一塔 0.818 秒。近战兵实测 **150 → 垫刀后 100 → 塔弹后 20 → 露娜击杀**；远程兵 **165 → 111 → 回血到 113 → 塔弹后 24 → 回血到 26 → 露娜击杀**。这里只验证给定顺序的实际伤害和归属；测试夹具按指定时序发起攻击，不是让练习器自动补刀。 |
| 程序回归 | 覆盖不垫、一垫、两垫、来不及、伤害浮动跨过死亡线、塔抢刀、普攻冷却，以及同一根兵条上从「垫」变成「等」再变成「出手」。WPF 用例检查不配对、不采集也能试算。 |

还没有用大量自然兵线对每次屏幕提示与最终补刀归属做配对统计。默认 HUD 以外的分辨率、色盲模式、皮肤、叠在一起的兵、车兵和超级兵均未验收。
