# 双机：游戏端不再传画面（只传自身 GSI）

2026-11-20 起游戏端默认不再把 Dota 画面传给教练端：

- 对手的等级和装备由教练机自己的 Plus 实时观战读取（[`twopc-plus-alerts.md`](twopc-plus-alerts.md)）。
- 补刀看游戏端本机画出的小兵血量数字（[`game-creep-hp.md`](game-creep-hp.md)）。
- 依赖画面的 AI 自动教练（打钱路线）和小地图校准随之停用。

视频代码全部保留，由 `Features.VideoUpload`（`desktop/DotaCoach.TwoPc.Core/Protocol.cs`）控制，默认关。界面上没有这个开关，要改代码重新构建。

## 现在传什么

| 方向 | 内容 | 频率 |
|---|---|---|
| 游戏端 → 教练端 | 自身 GSI（与以前附在每帧画面上的相同：英雄、阵营、比赛时钟、血量魔法、坐标、物品和技能冷却）和 Dota 窗口尺寸；`POST /v1/status`，一条 JSON，上限 32 KB | 每 0.25 秒 |
| 教练端 → 游戏端 | 字幕（链路测试、对手离开视野）、对手面板、游戏端缺的图标 | 游戏端每 0.1 秒问一次字幕，每秒问一次面板 |

每 0.25 秒发一次，是为了让教练端看到游戏时钟的每一秒，继续测 Plus 观战比游戏机慢多少。

连接方式不变：同一个配对码、固定证书的 TLS、会话。状态在教练端的作用和以前的画面一样：

- 教练端 4 秒没收到状态，就当游戏机离开：字幕撤回，面板不再下发。
- 字幕必须基于最近 22 秒内的某一条状态；换对局、换阵营、阵亡、改分辨率时撤回旧字幕。
- 状态不带图片：教练端不显示预览，也不会把它送进模型（`CloudCoach.Eligible` 要求有图）。

游戏端仍要找到 Dota 窗口：字幕和面板画在它上面，窗口尺寸也随状态发出。Dota 最小化或关闭时停发状态，教练端 4 秒后视为离开；恢复后自动继续，不用重连。

## 界面

- **游戏端**：去掉画面预览、传输速率行、“画面来源”和视频设置，“设置”折叠区只剩 Dota 目录。连接时不再弹出“确认游戏画面传输”。连上后状态行显示“已连接 · 只传自身GSI，不传画面”。
- **教练端**：去掉右侧的画面预览和“AI 自动教练”面板，以及“模型设置”“小地图校准”两个折叠区，窗口变窄；启动时不再配置模型，也不接受视频连接。离开视野字幕的显示秒数从“模型设置”移到“Plus 实时观战（实验）”折叠区。状态行显示“游戏端已连接 · 加密配对，不传画面”和最新一条状态是多少毫秒前收到的。
- 界面上不再有“诊断画面”来源。测试连接时开着 Dota（停在菜单也可以），在教练端 Debug 里点“发送测试提醒”。

## 版本兼容

两端要一起升级：

- 新游戏端连旧教练端（v0.4.2 及以前）：旧教练端没有 `/v1/status`，游戏端提示“教练端版本过旧”。
- 旧游戏端连新教练端：新教练端拒绝视频连接，旧游戏端报连接中断。

## 重新打开视频

把 `Features.VideoUpload` 的默认值改成 `true`，重新构建两端：视频、预览、模型、校准和原来的界面全部恢复，与 v0.4.2 相同。本地机器人局 E2E（`--local-bot-e2e`）本来就基于上传画面，不受这个开关影响。

## 测试

```bash
dotnet run --project desktop/DotaCoach.TwoPc.Tests -c Release
dotnet run --project desktop/DotaCoach.TwoPc.UiTests -c Release -- --game-controls
dotnet run --project desktop/DotaCoach.TwoPc.UiTests -c Release -- .tmp/twopc-ui-<新的目录名>
```

- **第一项**检查以下内容：
  - 状态让游戏机保持在线，但不会进模型。
  - 字幕可以基于状态，模型建议不行。
  - 状态的序号不能重复，诊断状态不能带 GSI，会话和窗口尺寸都要有效。
  - 4 秒没有状态后撤回字幕。
  - 经真实 TLS 发出状态后能收回字幕。
  - 没有视频解码器的教练端拒绝视频连接。
  - 旧教练端会给出对应的提示。
- **第二项**确认默认（视频关）的游戏端没有任何视频控件。
- **第三项**先打开开关，跑原有的视频、模型和校准测试；最后关掉开关，用真实的两端窗口确认以下几点：
  - 两端都没有预览、视频、模型或校准控件。
  - 教练端没有视频解码器，也没有配置模型。
  - 没有 Dota 窗口时，游戏端连上教练端但不发状态。
  - 诊断模式连上后只发状态，画面字节数为 0。
  - 测试字幕和对手面板都能到达游戏端。
  - 断开后会话结束。

  输出目录里的 `coach-status-only.png` 和 `game-status-only.png` 是两端截图。
