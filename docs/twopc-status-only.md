# 双机：只传本人 GSI，不传画面

**v0.6.1 的普通游戏端在新配置下默认不传视频。** 不需要改代码。在游戏端「设置 → 连接模式 / 画面来源」选择模式后再连接；配对不是采集或发送画面的授权。建议两端使用同版本。

| 游戏端选项 | 适合做什么 | 不会做什么 |
|---|---|---|
| **仅本人 GSI**（默认） | 记本人实战档案，收取本局授权的装备／眼位；显式开启后可收分钟路线 | 不采集屏幕，连本地小兵血量识别也停止；不是普通画面建议 |
| **本人 GSI＋可选本机小兵血量（可接收装备、眼位和分钟路线；不上传画面）** | 与默认模式一样带本人参赛凭据，可记档并收取本局授权的装备、眼位及已开启的分钟路线；同时允许本机显示小兵血量 | 选择模式不会自动开启识别；手动开启后也不编码、不上传画面或小兵识别结果 |
| **基础状态** | 只传本人基础 GSI 和窗口尺寸，接收普通无标记字幕；可手动开启仅在本机运行的小兵血量 | 不传视频，不提供参赛凭据、档案、装备／眼位图层、终局确认或分钟模型 |
| **诊断状态** | 发零画面的测试心跳，无需开 Dota。在教练端 Debug 点「发送测试提醒」，在游戏端窗口看提醒行 | 不传真人 GSI 或图像；不显示真实对局图层 |

另外两个选项需要显式选择：**Dota 2 游戏视频**采集真实画面，连接前另行确认；**诊断视频**发送合成图像检验视频链路，不发真实画面或本人 GSI。它们和「诊断状态」不是同一回事。

## 用本人 GSI 记档：是否同时看小兵血量

1. 教练端启动接收，复制配对码。游戏端核对本机 Dota 安装目录。要完全禁止本机采集，选默认「仅本人 GSI」；要在同一局看小兵血量和对手装备／眼位，选「本人 GSI＋可选本机小兵血量」。粘贴配对码并连接，按提示确认；已连接时要切换模式，先断开。游戏机首次安装或更新 GSI 配置后，在 Steam 的 Dota 启动选项加入 `-gamestateintegration`，完全退出并重开 Dota 一次。
2. 核对游戏端状态行：默认模式显示「不采集或传送画面」，已开启的[小兵血量识别](game-creep-hp.md)也会停止，连接期间不能再开。组合模式显示「允许本机血量识别 · 不传送画面」；已开启的识别会保留，没开时可点「显示小兵血量」，也可随时关闭识别而不断开配对。两种模式在教练端都没有视频预览，记本人对局都不需要 Plus、Debug 或模型。
3. 要看装备或守卫，在教练端接入[同局同阵营的 Plus 队伍视角](twopc-plus-alerts.md)，按需推送；读装备另需[视觉扫描](hero-scan.md)。实战眼位需支持的地图版本、已确认的小地图框及新鲜证据。授权显示与授权分钟模型使用团队信息彼此独立。
4. 只在想让模型规划时，按[7.42 分钟打钱](twopc-minute-farm-742.md)显式开启；先校准小地图，再确认本局、版本及 HUD。**不传画面不等于不开模型或不计费。** 普通画面模型没有图就不会推理；分钟模式可把结构化本人状态和模拟候选发给[教练机选择的服务](twopc-model-providers.md)。

## 两种带参赛凭据的 GSI 连接传什么

| 方向 | 内容及边界 |
|---|---|
| 游戏端 → 教练端 | 在已配对、固定证书的 TLS 会话中，约每 0.25 秒发送经校验的本人 GSI（对局号、阵营、英雄、游戏时钟、血蓝、可用的物品／技能等）与实际 Dota 窗口尺寸，不发像素、音频或观战全图。终局凭据单独送达；断线不是终局。 |
| 教练端 → 游戏端 | 按本局授权发送上次读到的对手装备、目击／推测眼位及缺少的图标；符合分钟模式条件时可另收路线和相应字幕。不是整份对局档案。 |
| 仅在教练机 | [本地实战档案与赛后复盘](twopc-match-information.md)。赛后录像要有可信终局并由人选择下载／导入，不会因为传 GSI 就自动下载，也不回填实战资料。 |

Dota 窗口不可用时不伪造小地图尺寸，不画标记；暂时失去窗口、暂停、阵亡和正式结束不是一回事。配对正常但没有图层，先检查本人 GSI、是否同局同队、教练端是否允许显示、是否已确认实际小地图，以及 Dota 是否在前台。不要开启视频来「修复」缺失的队伍视野。

## v0.4.3–v0.4.8 的旧状态链路（历史）

v0.4.3 于 2026-11-20 改为默认不传画面。当时用 `POST /v1/status`（JSON，最多 32 KB）约每 0.25 秒发本人状态和窗口尺寸；游戏机每 0.1 秒问字幕、每秒问面板，仍可测 Plus 观战相对玩家的延迟。教练机 4 秒未收到状态即视为离开；字幕必须基于 22 秒内的状态，换局、换阵营、阵亡或改分辨率会撤回。Dota 最小化时旧客户端停发状态。旧纯状态包没有视频预览、模型设置和小地图校准，离开视野字幕时长放在 Plus 面板里；v0.4.2 和 v0.4.3 不能混用。

旧版的 `Features.VideoUpload` 是编译时的默认选择，不是 v0.6.1 的使用步骤。旧版 UI 测试曾验证无采集时字幕／面板投放、断开撤回和零图片字节，输出 `coach-status-only.png`、`game-status-only.png`。兼容旧状态消息也**不表示**旧客户端具备新版的参赛凭据、档案、分钟模型或眼位授权。历史操作见 [v0.4.3 版本说明](twopc-v043.md)；新版操作以本页及包内 `README.md`、`MINUTE-FARM.md` 为准。
