# 双机：只传本人 GSI，不传画面

**v0.6.2 起游戏端不再往教练端传画面，也没有可选的视频模式。** 连接后游戏端只发本人 GSI 和 Dota 窗口尺寸；教练端推送的字幕、对手装备面板、眼位和分钟路线都画在游戏里。小兵血量在游戏机本地识别，随时可开关，连接不会打开或关掉它。两端请用同一版本。

| 方向 | 内容及边界 |
|---|---|
| 游戏端 → 教练端 | 在已配对、固定证书的 TLS 会话中，约每 0.25 秒发送经校验的本人 GSI（对局号、阵营、英雄、游戏时钟、血蓝、可用的物品／技能等）与实际 Dota 窗口尺寸，不发像素、音频或观战全图。终局凭据单独送达；断线不是终局。 |
| 教练端 → 游戏端 | 对手装备面板（上次读到的等级、装备和读取年龄）、目击／推测眼位及缺少的图标；离开视野、插眼推测、链路测试这类无标点字幕；开启分钟模式时的路线。不是整份对局档案。 |
| 仅在教练机 | [本地实战档案与赛后复盘](twopc-match-information.md)。赛后录像要有可信终局并由人选择下载／导入，不会因为传 GSI 就自动下载，也不回填实战资料。 |

## 使用

1. 教练端启动接收，复制配对码。游戏端核对本机 Dota 安装目录，粘贴配对码并连接，按提示确认。游戏机首次安装或更新 GSI 配置后，在 Steam 的 Dota 启动选项加入 `-gamestateintegration`，完全退出并重开 Dota 一次。
2. 游戏端状态行显示「已连接 · 只传本人 GSI，不传画面」。[小兵血量](game-creep-hp.md)在主页开关，连接前后都可以。教练端没有视频预览，记本人对局不需要 Plus、Debug 或模型。
3. 要看对手装备或眼位，在教练端接入[同局同阵营的 Plus 队伍视角](twopc-plus-alerts.md)并启动[视觉扫描](hero-scan.md)。**装备面板一直显示到本局结束：** 每个敌方英雄保留上次读到的等级和装备，读不到时只把年龄往上加，不会消失；换局、换阵营或本局结束才清空。眼位在教练端确认过小地图框时按框画，否则按游戏端「游戏内显示」里的小地图位置和大小画。
4. 只在想让模型规划时，按[7.42 分钟打钱](twopc-minute-farm-742.md)显式开启；先校准小地图，再确认本局、版本及 HUD。**不传画面不等于不开模型或不计费。** 分钟模式可把结构化本人状态和模拟候选发给[教练机选择的服务](twopc-model-providers.md)；分钟路线显示时，普通字幕不会盖住它。

Dota 窗口不可用时不伪造小地图尺寸。配对正常但没有面板，先检查教练端 Plus 观战是否同局同队、视觉扫描是否在运行、教练端「对手等级和装备」是否勾选，以及 Dota 是否在前台。

## v0.6.1 的连接模式（已移除）

v0.6.1 游戏端在「设置 → 连接模式 / 画面来源」里有六个选项：默认「仅本人 GSI」连接时会关掉本机小兵血量；「基础状态」收不到装备／眼位；另有游戏视频和诊断视频。那一版装备面板只在每个扫描读数、Plus 包和本人 GSI 都在 3 秒内对得上时才显示，读数时间一超前就撤回，所以时有时无（一局 20 分钟里撤回了 378 次）；没确认小地图框时也不画眼位，离开视野字幕只走视频连接。v0.6.2 去掉了这些选项，只保留「本人 GSI＋可选本机小兵血量」一种连接；其余模式只留给 UI 测试和本地机器人局验收。

## v0.4.3–v0.4.8 的旧状态链路（历史）

v0.4.3 于 2026-11-20 改为默认不传画面。当时用 `POST /v1/status`（JSON，最多 32 KB）约每 0.25 秒发本人状态和窗口尺寸；游戏机每 0.1 秒问字幕、每秒问面板，仍可测 Plus 观战相对玩家的延迟。教练机 4 秒未收到状态即视为离开；字幕必须基于 22 秒内的状态，换局、换阵营、阵亡或改分辨率会撤回。Dota 最小化时旧客户端停发状态。旧纯状态包没有视频预览、模型设置和小地图校准，离开视野字幕时长放在 Plus 面板里；v0.4.2 和 v0.4.3 不能混用。历史操作见 [v0.4.3 版本说明](twopc-v043.md)；新版操作以本页及包内 `README.md`、`MINUTE-FARM.md` 为准。
