3. Luna、英雄基类、单位、物品和技能五份配置在**只做 CRLF→LF**后，SHA256 与项目固定源逐项相等。
   原始字节哈希不同的原因明确记录为换行符，而不是忽略任意内容差异。

   没有将回放全图数据提供给实时规划器。

## 旧通行网格的 18 格差异

`GridNav:IsTraversable` / `IsBlocked` **不能单独当成包含树木碰撞的结果**。
本轮还对每个格点调用 `GridNav:IsNearbyTree(p,24,true)`；24 是测试 Luna 的实际 hull 半径。

- 原始 GNV 与运行时导航点查询有 43 格组合结果不同。
- 再计入引擎树木碰撞查询，与旧“静态树圆圈膨胀”的网格相比剩下 **18 格差异**，都是旧网格判阻挡、引擎点查询可通行。
- 差异坐标和两种值逐项保留，网页可勾选查看。
- 新的 `data/dota2-client-map.json` 保存引擎**初始状态点查询**网格；旧 `data/dota2-map.json` 未被偷偷改写，
  以免破坏历史复现或把新状态冒充旧实验。

这不是把路径问题全部解决：有限格点没有覆盖连续扫掠碰撞、走廊边缘、动态单位占位和实时砍树。
不以“网格已更换”为由恢复实战建议。

## 实际机制探针，而非模型估算

测试进程中新建 Luna，记录原始 `GetIdealSpeed` / `GetMoveSpeedModifier` 返回值及当时 modifier：

| 状态 | 引擎返回移速 |
|---|---:|
| 裸装 | 325 |
| 假腿＋未开启疯脸 | 370 |
| 实际施放疯脸后 | 392.199982 |

开疯脸同时观察到 `modifier_item_mask_of_madness_berserk`、蓝量变化和剩余冷却，
不是直接往统计里加一个常数。因此旧沙盒遗漏疯脸移动效果这一点得到实证。
这次是新建测试单位，**不是此前 10 级固定装备的收益场景或 GPM 验收**。

在路径采样点 `(32,2592)` 观察到 `modifier_path_movespeed`，该次含疯脸的移速变为约 **440.758575**。
这只支持该位置、当时朝向/状态下有加速；不能外推为整条河道的统一倍率。
保留了五条原始曲线控制数据，尚未推断或认证客户端的插值算法、方向计算、边缘衰减与完整作用体积。

树木局部探针选择来源坐标 `(-2560,-8704,128)`：

- 初始 `IsStanding=true`，引擎树碰撞查询为 true。
- `CutDown` 后二者变为 false。
- 显式 `GrowBack` 后二者恢复 true。

**这是单树砍倒/指令长回与碰撞变化的验证，不是自然长树延时的验证。**
另外记录了装备后走直线的逐时刻位置，不删除起步和停止阶段来伪造恒定速度。

## 工具与复现

```powershell
# Source2Viewer CLI 21.1 需位于参数所示路径，或显式传入另一个与 pin 相符的路径
npm run map:engine-probe -- "C:\Steam\steamapps\common\dota 2 beta" ".tmp/client-audit/runtime-map-tree-query.json"
npm run map:engine-probe -- "C:\Steam\steamapps\common\dota 2 beta" ".tmp/client-audit/runtime-mechanics.json" --mechanics
npm run map:client-audit -- "C:\Steam\steamapps\common\dota 2 beta" ".tmp/client-audit/vrf-21.1/Source2Viewer-CLI.exe"
# 重新读取本机资源，并确认输出与已保存结果一致；不再次启动游戏
npm run map:client-audit -- "C:\Steam\steamapps\common\dota 2 beta" ".tmp/client-audit/vrf-21.1/Source2Viewer-CLI.exe" --check
```

已有运行时证据不会覆盖，重新扫描请先另名保留。脚本版本和地图包 SHA256 必须与捕获一致；
地图在扫描过程中发生更新会拒绝结果。

引擎探针只启动自己拥有的独立进程：

- 发现现有 `dota2` 进程就拒绝，避免连接用户正在玩的游戏。
- 启用 insecure/LAN 与随机服务器密码，控制台连接走 `127.0.0.1`。
  **引擎 UDP 可能仍绑定通配地址，不能宣称这是操作系统级网络隔离。**
- 临时 Lua 使用专用文件名和独占创建；结束后只在 SHA256 未被别人改动时删除。
- 正常、错误或超时都终止自己启动的那个子进程，不按进程名批量杀游戏。
- 控制台只保存审计标记和相关脚本错误，不将无关 Steam/account 输出写入报告。
- VPK 只读提取，没有改包；生成文件、下载的工具和原始资源留在仓库 `.tmp`。

初次机制探针使用异步预缓存时未完成，随后遇到零玩家 retail 默认地图没有自定义 `GameModeEntity`；
这两次不是成功测试。改用新建测试单位及其 `SetContextThink` 后完整执行，失败记录保留于本机。
采集器现在对“收到 end 但 completed=false”同样非零退出，不能将脚本错误当通过。
