# v0.6.1 双机模型设置：Foundry 或 Codey（GitHub Copilot）

只在**教练机**选择模型。普通画面建议和 7.42 分钟规划使用同一个已选服务；游戏机仍只负责采集、传输和显示，不需要模型密钥或 Codey。两端使用同版本客户端。如果只想记录本人 GSI 或看赛后复盘，不必启用模型。

## 在教练端设置 Codey

1. 在教练机确认**自己管理的 Codey 模型网关**正在运行。发布者的教练机已安装 Codey 0.3.43；双机客户端不附带、不安装也不启动它。只检查模型配置时，可先取消「自动教练」，不必连接游戏。
2. 打开「模型设置」→「模型服务」，选 **「Codey · GitHub Copilot 本地代理」**。「Codey 本机模型 API 地址（仅回环，可改端口）」默认是 `http://127.0.0.1:4141/v1`。若自行更换端口，仍填教练机的回环地址，以 `/v1` 结尾；不要填游戏机地址、配对地址或管理接口。
3. 鉴权用 **Codey 模型网关密钥**，通过 `Authorization: Bearer` 发送。两种配置选一种：
   - 教练端进程已有环境变量 `CODEY_MODEL_API_KEY`：把「Codey 专用密钥文件路径（可选；不要填写密钥本身）」留空。如果刚在 Windows 用户环境中设置了变量，重新打开教练端。
   - 使用独立文件：在教练机的私有目录保存 UTF-8 文件，只放一行 `CODEY_MODEL_API_KEY=<模型网关密钥>`（尖括号内是占位说明）。用「选择…」选择本机绝对路径；界面保存的是**路径，不是密钥**。显式选的文件无效时，先修正文件，不会改用环境变量。

   **不要用** GitHub PAT、GitHub/Copilot OAuth 令牌、Codey Admin 密钥或 Foundry 密钥。不要选择账号缓存或通用 `.env` 文件，不要把密钥贴进界面、命令、日志、截图、仓库或发布目录。网关如何连接上游由使用者管理；教练端不代登录。
4. 在「Copilot 模型 ID」选择 `gpt-6.2-astra` 或 `gpt-6.2-sol`，点 **「刷新可用模型（不推理）」**。这是 `GET /v1/models`：只查目录，不发画面、GSI 或生成请求。下拉框中的两个名称是**允许选择的目标**，不是已开通的证明。
5. 确认清单列出了所选 ID 后，点 **「保存模型设置」**。仅刷新不会启用推理。重开教练端或换了服务、地址、密钥文件后，重新刷新并保存。准备好发送对局输入时再开启「自动教练」；满足所选模式条件后才会 `POST /v1/responses`，这可能消耗订阅额度或产生费用。

### 同名模型如何判定

Codey 也可能以同一裸 ID 公布其他供应商的模型，**不能只对名字**。教练端要求所选裸 ID 在目录中唯一、`display_name` 的来源标记是精确的 `github-copilot`，且 `supported_endpoints` 包含 `/responses`。这是 Codey 对**原生 HTTP Responses** 的能力标记：只列 `ws:/responses` 或只列客户端地址 `/v1/responses` 都不够。普通画面还要求目录明确声明 `vision: true`；若有图像上限，会按 Codey 的 data URL 算法检查，防止真实画面被静默换成占位图。分钟模式不传图，不要求视觉能力。

不发送给 Codex 别名、其他供应商的同名项，也不改走 Chat Completions、Messages 或 WebSocket。生成答复若未回报所选模型 ID，客户端会丢弃它。目录和答复都是**用户所运行网关的声明**：其自定义上游映射属于信任边界，客户端不能独立证明请求最终由哪个后端执行。

## 保留原来的 Foundry

旧配置未指定「模型服务」时仍使用 **「Azure AI Foundry」**。在「模型设置」选它，指定「Foundry 配置文件（服务地址与密钥）」和资源里的实际「Foundry 部署名」，再点「保存模型设置」。原文件中的 `AOAI_ENDPOINT`、`FOUNDRY_KEY` 和 Foundry 的 `api-key` 鉴权不变，不需要 Codey 或其模型清单。切回 Foundry 必须手动选择；Codey 失败不会触发切换。

## 哪些数据会发给模型

| 模式 | 发送条件和输入 |
|---|---|
| 普通画面建议 | 游戏端「连接模式 / 画面来源」显式选「Dota 2 游戏视频（采集并传送画面）」并确认，而非默认的「仅本人 GSI」。教练端需要新鲜本人 GSI 和真实游戏画面；若选 Codey，还要通过视觉能力检查。本机回环只表示**第一跳在教练机**，不表示上游离线推理。 |
| 7.42 分钟打钱 | 游戏端可选「仅本人 GSI（可接收装备、眼位和分钟路线；不采集画面）」。教练端开启「自动教练」「小地图路线」和「7.42 分钟打钱」，按提示确认小地图及本局 7.42 / build 6989。露娜／巨魔的分钟模型只收请求时的本人状态和模拟候选；仅勾选「允许分钟模型读取本队当时已知的装备、视野和推测眼位」才另加这些队伍信息。每个游戏分钟最多尝试一次，失败也计数。 |

切换服务不会开启额外采集，不改变配对、视频、GSI、对局档案或赛后 DEM 复盘；录像全图不进入任何实战模型。两种模式仍共用本次启动的请求上限和模型超时。

**鉴权失败、目录不可读、所选项不符合条件或推理失败，都不自动换服务、模型或 API，也不拿固定路线当作模型答案。** 可按现象排查：

- 连不上目录：核对教练机上的网关和回环地址。401 核对模型密钥的来源；403 核对模型访问权限。不要尝试账号或管理员凭据。
- 找不到所选项：核对裸 ID、来源和 HTTP Responses 声明。429 表示限流或额度问题，先处理配额或等待限流解除。配置修好后重新刷新清单并保存。
- 分钟模式可用，普通模式却没有建议：另查真实游戏画面、目录视觉声明和图像上限；“代理已列出”不代表能收图。
