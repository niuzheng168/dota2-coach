# 双机教练：游戏端的字幕、对手面板和小地图眼位设置

游戏端主页的「游戏里显示」四个勾选决定显示哪些内容（AI 打钱建议、对手提醒、对手装备面板、眼位）；「**设置 → 游戏内显示**」用来调整 Dota 画面上悬浮字幕、对手面板和小地图上目击／推测眼位的样子。设置只影响这台游戏机怎么显示，保存在 `%LOCALAPPDATA%\DotaCoach\TwoPc\game-overlay.json`，教练端看不到，也不用改。连接中、断开时都能改，改完立即生效。

## 字幕

| 设置 | 默认 | 范围与说明 |
|---|---|---|
| 显示哪些字幕（主页） | 都显示 | **AI 打钱建议**、**对手提醒（离开视野、插眼）** 分别开关。关掉的那一类不在游戏里显示字幕；游戏端窗口里的提醒行照常显示，并注明“不在游戏里显示”。AI 路线的小地图圆圈不受影响，由教练端“小地图路线”开关控制。链路测试提醒不受分类开关影响；「诊断状态」的测试字幕看游戏端窗口。 |
| 标题行 | 显示 | 字幕上方的小字，例如“视觉观察 · 未经核验”“AI打钱路线 · 非最优保证”。 |
| 左右位置 / 上下位置 | 居中 / 10 | 0–100。0 贴左（上）边，50 居中，100 贴右（下）边。字幕框始终完整留在 Dota 画面内；贴底时字幕变长会往上长。 |
| 字号 | 100% | 50–250%。100% 时 720p 下 28 像素，随游戏分辨率等比放大。 |
| 最大宽度 | 70% 画面宽 | 20–95%。字幕框随文字长短伸缩，超过这个宽度就换行。 |
| 文字 / 标题 / 背景颜色 | 金色 / 卡其 / 深蓝黑 | 15 种预设。在设置文件里手写的 `#RRGGBB` 会作为“自定义”保留。 |
| 文字不透明度 | 100% | 20–100%。 |
| 背景不透明度 | 82% | 0–100%。0 时只剩文字（文字带阴影，亮背景上也能看清）。 |

## 兵线小地图

两端使用支持兵线 HUD 的版本并配对；在教练端「设置 → 小地图校准」选左下/右下并确认。教练端「设置 → Plus 观战与扫描 → 兵线与迷雾推演」和游戏端「设置 → 游戏内显示 → 在小地图显示兵线与迷雾推演」默认开启，不依赖 AI 或所选英雄。绿是己方，橙是敌方；● 实见小兵、○ 最近所见的迷雾估计、△ 仅按时钟推算的一波、× 两侧接近。带 `~Ns` 的交汇是未来估计，`理` 是空线基线，`若守` 是假设最后的前沿没动。兵点按游戏秒更新；游戏端每轮取数后等待 0.75 秒，叠加层每 0.15 秒检查重绘，不在采样间插值。暂停、断线、对局/版本或 HUD 不符会撤掉兵线，不会清掉本局上次读到的对手装备。

## 对手面板

Plus 观战时敌方英雄的等级和装备（数据来自教练端的视觉扫描，见 [`twopc-plus-alerts.md`](twopc-plus-alerts.md)），在有授权且来源仍然有效时，贴着游戏画面左边显示：每行一个敌方英雄，头像、等级、六格装备、中立物品；读取满 30 秒标出“30秒前”，满 1 分钟后标出“N分前”并整行变暗，从没看到过的写“未见”。

面板有自己的透明窗口，大小正好是面板本身，只在内容变了时重画：等级、装备变了，或上面这个时间标签变了（30 秒时一次，之后每分钟一次）。游戏端定时向教练端取面板，内容没变就不重画。字幕和分钟路线使用另一个透明窗口；装备和眼位图层可单独存在。

| 设置 | 默认 | 范围与说明 |
|---|---|---|
| 对手装备面板（主页） | 显示 | 关掉后游戏里不画面板（教练端照样推送）。 |
| 上下位置 | 40 | 0–100。0 贴顶，100 贴底；默认在左侧中间偏上，避开左上角的击杀信息和左下的聊天、小地图。 |
| 大小 | 100% | 50–250%。100% 时 1080p 下每行约 21 像素高，一行约 320 像素宽。 |
| 不透明度 | 75% | 20–100%。整个面板一起变透明。 |

教练端只下发已授权的结构化面板，图在游戏端画，不上传游戏屏幕来画面板。本机已提取的英雄头像和物品图标可随自用游戏端包放在安装目录的 `icons\` 里（v0.4.x 的一份约 550 个、5 MB）；包里没有的（比如之后 Dota 版本新加的物品），游戏端向教练端要一次，教练端从教练机本地的游戏文件里取。暂缺图标时保留已读到的名称／栏位，不会拿别的装备补图。图标只从教练机本地提取的那一份打包，不进代码仓库；带图标的安装包只供自用，不要公开分发。

## 小地图：菱形是目击，问号是推测

- **实心菱形 ◆**：这队当时在小地图上看到的守卫。绿边是己方，红边是敌方；金色是侦查守卫（假眼），蓝色是岗哨守卫（真眼）。最后一次看到不等于现在仍在。
- **带 `?` 的虚线圈**：依据敌人携带数量减少及可见行踪作出的[插眼推测](twopc-enemy-wards.md)，首选位置也是推测。白色表示种类不明；大圈只表示大概区域。候选快到期的最后一分钟会变暗。
- **①②③**：[分钟打钱路线](twopc-minute-farm-742.md)的先后目的地，不是眼位。关掉 AI 字幕不会把路线圈一起关掉；关掉眼位也不会清空装备面板。

实战眼位画在独立、鼠标穿透的小窗口内，只覆盖小地图。教练端须开眼位推送，并有当局队伍信息。教练端为当前分辨率确认过小地图框时按那个框画；没确认时按下表的「小地图在右侧」和「小地图大小」画（与 v0.4.8 相同），所以自定义或超大小地图请先在这里调准。

| 游戏端设置 | 默认 | 作用 |
|---|---|---|
| 眼位（目击与推测）（主页） | 开 | 只管本机画不画；不改变教练端的记录、推送或模型授权。 |
| 小地图在右侧 | 关 | 镜像 HUD 时打开：教练端没确认小地图框时，眼位画在右下；未连接时的蓝色虚线参考框也随之移动。 |
| 小地图大小 | 100% | 70–160%。默认边长是画面高度的 2/9（1080p 为 240 像素，4K 为 480 像素）；用「预览 8 秒」的蓝框对准游戏里的小地图。教练端确认过的框优先。 |

## 预览和推送

改设置或点「预览 8 秒」可看字幕样式；未连接时还可看示例面板及蓝色参考框，不会伪造目击或推测。真实面板与路线只在 Dota 前台显示。用无边框或窗口模式，将 Dota 和游戏端放在不同屏幕可边调边看；最小化后没有可画的游戏窗口。「恢复默认」回到上表默认值。

字幕显示时长、「游戏字幕」「小地图路线」和 Plus 推送开关在教练端设置。游戏端的显示偏好不会授权队伍数据进入模型，见[对局档案](twopc-match-information.md)。游戏端[不传画面](twopc-status-only.md)，这些图层都经本人 GSI 连接收到。

## 和 v0.4.2 默认字幕的区别

- 字幕框随文字长短伸缩，原来固定约 70% 画面宽。短提醒（比如“剃刀 离开视野 · 最后在中路”）不再拉一整条。
- 默认位置还是顶部居中，略高一点：原来字幕框顶边在画面高度 10% 处，现在是剩余空间的 10%。
- 文字加了阴影，背景框是圆角。

这些字幕样式在 v0.4.3 引入，独立面板窗口在 v0.4.4 引入。新档案和校准眼位使用配套的 v0.6.1 客户端，不能用早期版本的混用说明判断兼容性。

## 测试

```bash
dotnet run --project desktop/DotaCoach.TwoPc.Tests -c Release
dotnet run --project desktop/DotaCoach.TwoPc.UiTests -c Release -- .tmp/twopc-ui-<新的目录名>
```

核心测试检查显示偏好的保存、读回、非法值、位置和尺度换算。UI 测试操作真实设置控件并离屏渲染像素，可核对字幕位置／透明度、半透明面板、读取年龄和图标。地图另有校准、已授权目击／推测和分钟路线的检查；离线样式示例不作为实战来源。v0.4.x 的留档图名包括 `caption-default.png`、`caption-bottom-left.png`、`enemy-panel.png`、`game-overlay.png`、`ward-marks.png`；其首选眼位使用旧图例。

## 游戏机实测（2026-11-19）

游戏机（3840×2160 无边框，主屏 4K/240 Hz）上用官方英雄试玩、真实 Dota 窗口跑了 `DotaCoach.TwoPc.UiTests.exe --panel-trial <图标目录> <输出目录>`：进程内一个本机回环的教练端发布固定的 5 名敌方英雄示例面板和 18 个真实图标，真的游戏端窗口用诊断画面连上去，在 Dota 上画面板；只为这次测试把悬浮窗口设成可截图。结果：

- 3 项检查通过：取到面板和图标、断开后面板消失（235 ms）、窗口正常关闭。
- 默认面板在左边、离顶约 36%，4K 下 624×240 像素；150%、不透明、置顶时 937×360，五行都完整，盖住左上角 Dota 菜单图标。关掉开关后面板不画。
- 三段各 20 秒（开 / 关 / 再开），每秒 10 次检查：开着时 186/186 次都在，没有闪烁。测试进程 CPU 占整机 2.4–2.8%（含进程内的教练端解码和诊断视频编码，开关面板差别在噪声内）。没有做游戏帧率的对比测量。
- 问题：试玩模式左侧展开的控制面板上亮的文字会透过面板，较难看清。之后把每行自己的暗底从 43% 加深到 78%、一分钟以上的行从 60% 改为 70% 不透明，并在本机用游戏机的截图做背景复查。真实对局里左侧大多是地形，对比没这么强；仍嫌花的话把“不透明度”调高。

这是固定示例装备面板的 4K 测试；不验证真人 Plus 整条链路的时效、分钟路线或小兵识别性能。
