# 双机教练：游戏端的字幕和对手面板设置

游戏端的“**游戏内显示：字幕和对手面板的开关、位置、大小、颜色、透明度**”折叠区（默认收起）用来调整 Dota 画面上悬浮字幕和对手面板的样子。设置只影响这台游戏机怎么显示，保存在 `%LOCALAPPDATA%\DotaCoach\TwoPc\game-overlay.json`，教练端看不到，也不用改。连接中、断开时都能改，改完立即生效。

## 字幕

| 设置 | 默认 | 范围与说明 |
|---|---|---|
| 显示哪些字幕 | 都显示 | **AI 打钱建议**、**对手离开视野（Plus 观战）** 分别开关。关掉的那一类不在游戏里显示字幕；游戏端窗口里的提醒行照常显示，并注明“不在游戏里显示”。AI 路线的小地图圆圈不受影响，由教练端“小地图路线”开关控制。链路测试提醒总是显示。 |
| 标题行 | 显示 | 字幕上方的小字，例如“视觉观察 · 未经核验”“AI打钱路线 · 非最优保证”。 |
| 左右位置 / 上下位置 | 居中 / 10 | 0–100。0 贴左（上）边，50 居中，100 贴右（下）边。字幕框始终完整留在 Dota 画面内；贴底时字幕变长会往上长。 |
| 字号 | 100% | 50–250%。100% 时 720p 下 28 像素，随游戏分辨率等比放大。 |
| 最大宽度 | 70% 画面宽 | 20–95%。字幕框随文字长短伸缩，超过这个宽度就换行。 |
| 文字 / 标题 / 背景颜色 | 金色 / 卡其 / 深蓝黑 | 15 种预设。在设置文件里手写的 `#RRGGBB` 会作为“自定义”保留。 |
| 文字不透明度 | 100% | 20–100%。 |
| 背景不透明度 | 82% | 0–100%。0 时只剩文字（文字带阴影，亮背景上也能看清）。 |

## 对手面板

Plus 观战时敌方英雄的等级和装备（数据来自教练端的视觉扫描，见 [`twopc-plus-alerts.md`](twopc-plus-alerts.md)），贴着游戏画面左边一直显示：每行一个敌方英雄，头像、等级、六格装备、中立物品；读取超过 10 秒的标出“N秒前”，超过 1 分钟的整行变暗，从没看到过的写“未见”。

| 设置 | 默认 | 范围与说明 |
|---|---|---|
| 显示对手面板 | 显示 | 关掉后游戏里不画面板（教练端照样推送）。 |
| 上下位置 | 40 | 0–100。0 贴顶，100 贴底；默认在左侧中间偏上，避开左上角的击杀信息和左下的聊天、小地图。 |
| 大小 | 100% | 50–250%。100% 时 1080p 下每行约 21 像素高，一行约 320 像素宽。 |
| 不透明度 | 75% | 20–100%。整个面板一起变透明。 |

教练端每秒只发名字、等级和读取时间，图在游戏端画。英雄头像和物品图标（Dota 自己的美术，约 550 个、5 MB）打包在游戏端安装目录的 `icons\` 里；包里没有的（比如之后 Dota 版本新加的物品），游戏端向教练端要一次，教练端从教练机本地的游戏文件里取。还没拿到的图标显示成灰色方块。图标只从教练机本地提取的那一份打包，不进代码仓库；带图标的安装包只供自用，不要公开分发。

## 预览

改任何一项，或点“预览 8 秒”，Dota 画面上会显示 8 秒示例字幕和示例对手面板；正好有真实的提醒或面板时显示真实的。平时字幕和面板只在 Dota 位于前台时显示；预览期间游戏端窗口在前台也会显示，所以 Dota 放一块屏幕、游戏端放另一块屏幕，可以边调边看。Dota 要用无边框窗口，最小化或独占全屏切出后没有地方显示。“恢复默认”回到上面两表的默认值。

这些仍在教练端设置：字幕显示几秒（“模型设置”的字幕秒数）、AI 建议发不发字幕（“AI 自动教练”的游戏字幕开关）、对手面板和离开视野推不推送（“Plus 实时观战”折叠区）。

游戏端默认已不传画面（[`twopc-status-only.md`](twopc-status-only.md)）。在代码里重新打开视频时，悬浮字幕和面板也不会进入传给教练机的视频（悬浮窗口设为不被屏幕采集），所以教练端预览里看不到它们。

## 和 v0.4.2 默认字幕的区别

- 字幕框随文字长短伸缩，原来固定约 70% 画面宽。短提醒（比如“剃刀 离开视野 · 最后在中路”）不再拉一整条。
- 默认位置还是顶部居中，略高一点：原来字幕框顶边在画面高度 10% 处，现在是剩余空间的 10%。
- 文字加了阴影，背景框是圆角。

需要 v0.4.3 游戏端。v0.4.3 起游戏端不传画面，旧版游戏端连不上 v0.4.3 教练端，两端要一起升级。

## 测试

```bash
dotnet run --project desktop/DotaCoach.TwoPc.Tests -c Release
dotnet run --project desktop/DotaCoach.TwoPc.UiTests -c Release -- .tmp/twopc-ui-<新的目录名>
```

第一项检查默认值、位置换算（贴边、居中、字幕框比画面还大）、按类型隐藏、非法值，以及设置文件的保存、读回、缺字段、超范围、损坏。第二项操作真实游戏端窗口里的滑块、开关和颜色，确认设置立即交给悬浮窗口并保存，被隐藏的类型在窗口里有注明；确认游戏端经真实连接取到对手面板和图标；再把悬浮窗口的绘制代码离屏渲染成图逐像素检查：字幕的默认位置和背景透明度、左下角红底白字、字号放大、窄宽度换行、背景全透明、去掉标题行、隐藏类型只留地图圆圈；对手面板贴左、按设置的高度、头像和装备画成图片、75% 不透明、等级、“N分前”、旧行变暗、“未见”，以及大小和位置跟随设置；最后“恢复默认”。输出目录里的 `caption-default.png`、`caption-bottom-left.png`、`enemy-panel.png`、`game-overlay.png` 是渲染结果和设置面板截图；本机提取过 Dota 图标时还有 `enemy-panel-1080p-real-icons.png`（1080p、真实图标）。

## 游戏机实测（2026-11-19）

游戏机（3840×2160 无边框，主屏 4K/240 Hz）上用官方英雄试玩、真实 Dota 窗口跑了 `DotaCoach.TwoPc.UiTests.exe --panel-trial <图标目录> <输出目录>`：进程内一个本机回环的教练端发布固定的 5 名敌方英雄示例面板和 18 个真实图标，真的游戏端窗口用诊断画面连上去，在 Dota 上画面板；只为这次测试把悬浮窗口设成可截图。结果：

- 3 项检查通过：取到面板和图标、断开后面板消失（235 ms）、窗口正常关闭。
- 默认面板在左边、离顶约 36%，4K 下 624×240 像素；150%、不透明、置顶时 937×360，五行都完整，盖住左上角 Dota 菜单图标。关掉开关后面板不画。
- 三段各 20 秒（开 / 关 / 再开），每秒 10 次检查：开着时 186/186 次都在，没有闪烁。测试进程 CPU 占整机 2.4–2.8%（含进程内的教练端解码和诊断视频编码，开关面板差别在噪声内）。没有做游戏帧率的对比测量。
- 问题：试玩模式左侧展开的控制面板上亮的文字会透过面板，较难看清。之后把每行自己的暗底从 43% 加深到 78%、一分钟以上的行从 60% 改为 70% 不透明，并在本机用游戏机的截图做背景复查。真实对局里左侧大多是地形，对比没这么强；仍嫌花的话把“不透明度”调高。

还没验证：真人 Plus 对局里扫描数据一路推到游戏机的完整流程。
