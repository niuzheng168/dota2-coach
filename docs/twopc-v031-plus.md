# 双机教练 v0.3.1：教练机 Plus 实时观战（实验）

本版在 v0.3.0 的基础上新增两项：**教练机接收本机 Dota 的 Plus 实时观战数据**，以及**一键配置 GSI**。

- 视频、配对和自动教练的协议没有变化，v0.3.0 游戏端仍能连接 v0.3.1 教练端。
- 但游戏端的 GSI 配置有变化，建议两端一起升级。

**Plus 数据目前只显示和记录，不送进自动教练。** 要等实测确认延迟和数据可靠后，再决定是否接入。

## 新增了什么

| 位置 | 功能 |
|---|---|
| 教练端 · “Plus 实时观战”面板 | 一键为本机 Dota 写入观战 GSI 配置，并启动本机接收（`127.0.0.1:3220`）。实时显示：观战模式、游戏时间、阵营、小地图单位数、己方英雄数、视野内敌方英雄和野怪数，以及**比游戏机慢多少** |
| 教练端 · 复制启动参数 | 读取 Steam 已保存的 Dota 启动选项，补上 `-gamestateintegration` 后复制到剪贴板 |
| 游戏端 | 显示启动参数检查结果和“复制启动参数”按钮；GSI 配置增加 `minimap`，并显示**玩家模式下有没有小地图数据**（只在本机统计数量，不上传） |
| Debug（教练端） | 开启后，每秒记录一次观战小地图的类型化数据（单位名、阵营、坐标、视野、图标），每 10 秒记录一次延迟统计 |

只读取 Steam 的 `localconfig.vdf` 文件，**不访问 Dota 进程**，也**不修改 Steam 文件**（Steam 运行时会覆盖改动）。启动参数需要你自己粘贴到 Steam。

## 使用步骤

### 一次性准备

- **两台机器**：在 Steam 的 Dota 2 启动选项里加上 `-gamestateintegration`。客户端里的“复制启动参数”会生成“原有参数 + 该参数”。
- **教练机**：用账号 B 登录 Steam。B 需要有 Dota Plus，并与游戏账号 A 互为好友。

### 游戏机（X，账号 A）

1. 运行 v0.3.1 游戏端，粘贴配对码，点“连接并开始”。
2. 客户端会自动更新 GSI 配置。如果提示“已写入/更新”，需要**完全退出并重启 Dota 一次**。
3. 正常排一局**真人对局**。本地机器人局无法被 Plus 观战。
4. 对局开始后，看“玩家模式小地图”一行：
   - 显示“有，N 个单位”：自己的 GSI 就能直接提供队伍视野内的小地图。
   - 显示“没有收到”：小地图只能从 Plus 观战获取。

### 教练机（Y，账号 B）

1. 运行 v0.3.1 教练端，在“Plus 实时观战”面板核对本机 Dota 目录，点 **一键配置观战 GSI**。
2. 如果提示“已写入”，**完全退出并重启本机 Dota 一次**。之后每次打开教练端都会自动连接，不需要再点。
3. 等 A 的对局开始后，在好友列表右键 A，选 **实时观战**（Plus，不是有延迟的普通观战）。
4. 面板应显示“Plus 实时观战 · 队伍视角”和对局数据。游戏机视频连着时，会显示 **比游戏机慢：中位 X.XXs**。
5. 需要事后分析时，在开局前展开 Debug 并勾选录制。数据保存在 `%LOCALAPPDATA%\DotaCoach\Debug`。

可选的对照：最后几分钟改用普通（有延迟）观战。面板会显示“完整观战（有延迟，含10人数据）”，并单独统计这段延迟，不会和实时观战的数据混在一起。

## 延迟怎么算

- 游戏机的自身 GSI 时钟本来就随视频帧传到教练机。
- 教练端用**同一台机器的单调时钟**，记录两个时刻：
  - 游戏机第一次显示游戏时间到达第 T 秒的时刻：帧到达时刻减去 GSI 年龄；
  - 本机观战第一次显示到达第 T 秒的时刻。
- 两者相减，取最近 300 秒的中位数和 P10、P90。**不需要两台机器的时钟同步。**
- 视频编码、传输和解码本身有延迟，所以结果会**偏低约 0.1–0.2 秒**。GSI 发送间隔（游戏机 0.2 秒、观战 0.1 秒）也会带来几百毫秒以内的抖动。
- 如果双方的 matchid 都已知但不一致，面板会提示“观战的不是游戏机这一局”，不会把数据混进统计。

## 边界

- Plus 数据只用于显示、记录和测延迟，**不会进入模型输入，也不会生成提醒**。
- 迷雾过滤、同名英雄多条目、视野为 0 的静止条目，这些语义都还没有验证。
- 游戏端的小地图数据只统计数量，原始 GSI 仍不离开游戏机。
- 已验证：核心检查 189 项、两个原生客户端的 UI 检查 62 项。其中包括一键配置、合成观战数据显示，以及在真实教练窗口里从游戏机帧测出约 0.15 秒的注入延迟。**还没有用真实 Dota Plus 观战跑过。**
