# 双机教练 v0.4.2：使用说明（界面简化版）

v0.4.2 只简化了两端界面，视频、配对、GSI 和自动教练的行为与 v0.4.1 相同。两端都用 v0.4.2，升级后重新复制配对码。

## 教练机

1. 解压教练端 ZIP，运行 `DotaCoach.CoachClient.exe`。程序启动后自动开始接收。
2. 核对“本机地址”：跨机必须是游戏机能访问的局域网 IP，不要选 WSL 虚拟网卡；`127.0.0.1` 只用于同机。要改地址，先点“停止接收”，改好再点“启动接收”。
3. 点“复制配对码”，用私下的方式传到游戏机。配对码含连接密钥。怀疑泄露时点“撤销配对”，再重新复制。
4. 右侧“AI 自动教练”有三个开关：自动教练、游戏字幕、小地图路线，默认都开。**开着自动教练会把画面和自身GSI发到云端模型并计费**，只测连接或延迟时请先关掉。

其余设置默认收起，一般不用动：

| 折叠区 | 内容 |
|---|---|
| 模型设置 | Foundry `.env` 文件（密钥只在教练机读取）、部署名、调用间隔和请求上限、字幕显示秒数、模型超时 |
| 小地图校准 | 默认 HUD 用自动左下框即可。镜像 HUD 或超大小地图：点“预设：左下/右下”或填左、上、边长，再点“确认校准” |
| Plus 实时观战（实验，只记录） | 一键配置观战 GSI、复制启动参数、观战数据与延迟 |
| Debug | 开启 Debug 记录、打开 Debug 目录、发送测试提醒（不经过模型，检查游戏机能否收到字幕） |

## 游戏机

1. 解压游戏端 ZIP，运行 `DotaCoach.GameClient.exe`。
2. 粘贴配对码，点“**连接**”，确认画面传输说明。连接后按钮变成“断开”。
3. 第一次连接会自动写入自身 GSI 配置。提示“已写入/更新”时，完全退出并重启 Dota 一次。Steam 里 Dota 的启动选项要含 `-gamestateintegration`，状态区会显示检查结果。
4. Dota 请用“无边框窗口”：最小化时没有画面可传。

状态区一共三块：连接状态、视频（分辨率、帧率、码率、编码器）、自身GSI（英雄与游戏时间、小地图单位数、启动参数检查）。

默认收起的折叠区：

| 折叠区 | 内容 |
|---|---|
| 设置 | 画面来源（Dota / 诊断画面）、帧率、传输分辨率、编码器、码率、采集方式、Dota 安装目录、复制启动参数 |
| Debug | 开启 Debug 记录（不存图片；对局中每秒记录小地图明细）、打开 Debug 目录 |

## 相比 v0.4.1 删掉或合并了什么

- 游戏端：“连接并开始”和“停止 / 断开”合并成一个按钮；GSI 状态、启动参数、小地图三行合成一块；删除“导出本次 GSI 配置”（已自动配置）。
- 教练端：“启动局域网接收”和“停止”合并成一个按钮；收到的帧数和自身GSI合成一块；**删除“人工联调”**（测试文字、冻结预览、点选标记、坐标输入、5 秒延迟回传），改为 Debug 里的一个“发送测试提醒”按钮；**删除“本地 Ollama 视觉诊断”**（本地模型未部署，自动教练不依赖它）。
- 包内说明精简为本文件，以及 `PLAYER-MINIMAP.md`、`PLUS-SPECTATOR.md`、`VIDEO-v040.md`、`DEBUG-DETAILS.md`。旧说明中的按钮名以本文件为准。
