# 7.42 清一营：赏金能查，清空时间要带条件

**已知是哪几只怪，才报这一营的金币。已知攻击面板、姿态、技能和能打到哪些副目标，才估计清空时间。** 本工具是离线的普通攻击对照，不读实时隐藏单位，不推断地形/移动，不把同档营地当成同一包怪，也不把理想攻击时间当作安全打野时间。

## 直接运行

在仓库根目录使用项目的 Node 环境；查表、估算和读取已发布的实测均不需要 Steam 或网络。

```powershell
node scripts/client/camp-742.ts --unit centaur_khan 610    # 大人马的原始字段，以及 10:10 当档毛赏金
node scripts/client/camp-742.ts --catalog 610              # 每个实际见过的整组单独报价，不求同档平均
node scripts/client/camp-742.ts --example luna
node scripts/client/camp-742.ts --example troll-melee
node scripts/client/camp-742.ts --example troll-ranged
node scripts/client/camp-742.ts --input generic             # 可复制的自定义面板 JSON
node scripts/client/camp-742.ts --file my-camp.json         # 或把 JSON 送到 --stdin
node scripts/client/camp-742.ts --evidence                  # 全部对照的分母、误差、拒绝原因
node scripts/client/camp-742.ts --evidence 9100049738
```

**可照算的例子：10:10，大人马先，小人马两只。** 一档升级后的 HP 分别为 1130、380、380；无额外护甲效果时护甲是 4.5、1.5、1.5。整营基础毛赏金 `49–54 + 2×(16–18) = 81–90`，此时则是 **81–93 金**。同一档、相同组成，换英雄或攻速不会提高毛赏金。

```json
  },
  "formation": { "cleave": "all" }

```

- [模块 `estimateCamp742(input)`](../src/tactics/camp-742.ts) 接受精确的单位列表（可重复，顺序是主目标优先级）。`full-unstacked` 断言自然、满血、单营无叠野，且组成必须在观测目录内；`listed-units` 仅对指定的满血单位报价，**不声称整营已清空**。只想查钱时可不传 `attacker`。
- `damage` 是包含主属性、装备白/绿字、露娜自身祝福等常驻加成后的**实际攻击上下限**；不含压制和对方减伤。`attackSpeed` 是 100 基准的总攻速，不是每秒攻击次数；已计入敏捷、假腿等被动，不含建模的热血战魂、已开启疯脸的加速。两者都不从“英雄名＋一件装备”补猜。`weapon` 只指定额外攻击机制：`none` / `quelling_blade` / 普通 `bfury`。泛用 `hero:"generic"` 必须再给实际 `bat` 和 `mode`；只适用于没有额外攻击机制，或特意关闭它们的物理普攻。
- `timing.firstHitToLastDeathSeconds` 是情景跨度；**第一击已落下为零点**，一击全灭就是 0。没有起手实测时，`engageToLastDeathSeconds` 为 `null`。只有显式提供 `engageToFirstHitSeconds`（自行量得的接敌到首个命中的延迟）才相加。另一个地形/移动模块的路程不在本项内，勿双计接近、转身或飞行。
- `bounty.listed` 是所列单位在同一升级档被击杀的实体毛赏金上下限；`wholeCamp` 才是可报的整营毛额。不是期望、整队收入、净收益、GPM 或保底到账。未消歧的整营/属性/覆盖、含未支持效果、跨升级边界等返回 `null` 和原因；**不要用 0 或旧版均值填空**。

## 伤害模型做了什么

1. 主目标按给定顺序攻击；用 `BAT × 100 / 总攻速` 计算间隔，各单位按自身护甲 `1 − 0.06a/(1+0.06|a|)` 取物理伤害倍率。满血开始，按时间加基础回血且不超上限；离散攻击、溢出不转移。分别跑固定最低/最高攻击掷值；返回的是**这些情景**的最快/最慢，不是概率置信区间。
2. 月刃弹距 500，等级 1–4 分别 **3/4/5/6** 弹，逐跳减伤 **50/45/40/35%**；指定减衰减天赋再减 5 个百分点。对每个副目标只过一次它自己的护甲。输入 `glaive:"all"|"none"`，或按目标下标给每一跳的可达邻接表；优先尚未弹过的活目标，必要时可回弹、不能原地自弹。实际选靶顺序不是从 KV 恢复的。`hopSeconds` 是显式的每跳情景延迟，默认 0；不当作真实弹速。源文件还列物品效力每弹下降 40%；没有重建通用 on-hit 体系，不将压制、暴击、吸血等无据叠到月刃。
3. 巨魔普通远程 BAT **1.7**，固定近战用姿态特殊值 **1.4**，不是总拿网络基础 BAT 1.7。热血战魂每层 **15/20/25/30** 攻速，最多 10 层，天赋可再 +4/层；初始新目标零层，连续命中叠层，换主目标重置。远程致残触发率数据为 20%，直接额外物理伤害 **10/15/20/25**；模型不预测伪随机序列，用不触发/每次触发展示敏感性。近战缠绕不凭空增加伤害。
4. 普通狂战斧面板 +50 不重复计入；对非英雄主目标近/远压制 +10/+5，补刀斧 +8/+4。狂战近战打野用 **40%** 劈斩，不是对英雄的 60%，远程无劈斩。KV 劈斩起宽 150、末宽 360、距离 650；不从“同一营”推断方向和命中。调用者给 `cleave:"all"|"none"` 或每个主目标身后能命中的单位下标。情景对副目标按 `(面板攻击+压制) × 40%` 后用其自身护甲。若传已知 `madnessRemaining`（0–6 秒），按实际剩余窗口额外 +100 攻速，跨到期的攻击间隔按速率分段，不看到装备就假设开启。
5. 只输出 **1–20 分钟**内可完成的物理普攻情景；有效攻速建模域 20–700、单营最多演算 120 秒，超出不把截断值当答案。没有模拟施法/魔抗伤害、走位拉扯、攻击前摇或距离变化、丢失/闪避、攻速减益、肉身存活/续航、主目标选择优化、技能触发以外的暴击/电锤、幻象、多来源攻击、碎片或神杖。假设怪物没有释放会改变结果的主动技能、没有外部光环；固有的护甲、最大血量或回血光环未解决时（大萨特、花岗岩、黑龙、枭兽、部分远古）连时间也不报。泥土傀儡碎片和召唤骷髅不按初始包结算，金色变体不套普通表。

## 16 份 DEM 实测：钱和时间分别验

**钱：适合报价；时间：适合比较站位/技能假设，不适合作为实战倒计时。** [逐段证据](../data/farming-742-camp-comparison.json)保留正例和未能做属性对照的段落、来源 DEM 哈希、单位 ID、出生器、首击/首杀/末死 tick；属性可还原的段落另附输入和原始面板，不用实际时长反推攻速或乘一个校准系数。

- 原 16 份完整 `facts.json` 有整图每秒状态但没有 `DAMAGE`。因此重新解析**全部 16 份 DEM 至终局**，前 20 分钟另提取逐 tick 的血量/生命状态变化、所有攻击者的对野伤害/死亡、本体面板、独立的中立强化槽 17，以及给该英雄的 reason 14 金钱。额外采集的 `route_core` 不混入此分母；只有英雄自己的伤害目标名、没有可对应的全图实体血量变化时，不以“附近同名怪”补归属。
- 先用相同 tick、怪名、全图实体掉血/死亡做关联，再要求本体阵营及明确非幻象、第一下前满血、所有初始单位有独立出生器和死讯。所有有效伤害必须来自本体；每个同 tick 桶的掉血总量与伤害合计在整数取整容差内。多个同名目标同时掉血时，只允许所有候选都在同一批次且伤害条数足够；不伪造逐刀指向。对照需要主目标时，只接受唯一实体，或全部合法“伤害值↔血量差”配对都给出同一个主目标。首击至末死期间若同营另有一批活怪则排除。
- 2,446 个出生批次中得到 **368 段**明确的首伤→末死：露娜 223、巨魔 145，两个英雄各覆盖原 8 场。不是 368 次连续站桩：10 段相邻两次本体伤害相隔至少 10 秒；**6 段首杀、末杀处于同 tick**，也不能解释为瞬清。另有队友参与/伤害证据缺失、20 分钟时尚未全死、叠营重叠、会召唤等，拒绝原因分项在 JSON。
- **静态赏金独立交叉核对：**364 段在同一可报价档内，**364/364** 的静态整组上下限都分别等于该批各实体临死 `m_iGoldBountyMin/Max` 之和。346 段能唯一汇总同 tick 的玩家 reason 14；其中同档 342 段，**341/342** 到账落入毛区间。唯一落外的是 `9098789898 / evil_15`：按实体为 66–74，到账 **53**；该批出生时前一批仍有 `2060:133` 活着，到首击时才不再重叠。排除出生时仍有旧怪的同档批次后是 **340/340**。这证明**毛赏金不总是玩家实收**，没有从差额反推叠野人或分成比例。
- **时间对照：**只保留能从首击前面板、槽位、姿态、技能还原攻击区间与基础 IAS，并且期间没换面板/装备、没有飞斧/月刃轨道等未建模伤害的段落。攻速用基类 + 网络总敏捷 + 支持的装备/强化显式攻速；不是用本营下一次命中的时间拟合。疯脸/大招持续状态不确定、主动伤害、未核装备或被动等都不硬比。露娜的可达图取首击前最近一个整图秒帧；巨魔朝向无法观测，分别跑劈全/劈不到。两者都不根据最后死讯挑一个“最准”的输出。
