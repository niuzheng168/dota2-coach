# 教练端的 7.42 地图和野怪

教练端用的地图数据是 `data/dota2-coach-map.json`，由 `scripts/client/build-coach-map.ts` 从本机已安装的 Dota 客户端（7.42，build 6989，`game/dota/maps/dota.vpk`）提取。2026-11-21 的 6986 → 6989 更新没有改地图文件，重新提取只变了 build 号。它用在：

- Plus 观战的**离开视野**提醒和**插眼推测**里的地点名（“最后在我方下路一塔大野”“可能在敌方上路边缘水生中野”）；
- 插眼推测排除放不了守卫的区域；
- 普通画面教练从本版营地和防御塔选己方地标，再把世界坐标投影到游戏小地图；7.42 的小地图范围未变（左上角 (-9472, 9472)，边长 18944）。

只是静态地形：不知道营地有没有被清、被拉、被升级，也不知道哪片区域归谁控制。

本页讲教练端的地点名、禁眼区和坐标投影。旧模拟器仍有 7.41f 的 `data/dota2-map-reference.json`；[7.42 打钱研究](farming-742-field-guide.md)和[客户端分钟规划](twopc-minute-farm-742.md)使用单独的 7.42 回放、地形与模拟资产，不能把旧地图路线当作该版本的实战建议。

## 内容

| 项目 | 数量 | 来源 |
|---|---|---|
| 野怪营地 | 28（每方 14：3 小、7 中、3 大、1 远古） | `npc_dota_neutral_spawner` 的位置和大小，刷怪框是同名的 `trigger_multiple` |
| 营地的怪物池 | 天辉 / 夜魇各自的小、中、大野，远古野两边共用，6 个水生营地（蛙） | 刷怪点的 Min/MaxSpawnType（1–3 天辉，4–6 夜魇，7 水生）；每种池子里可能刷的怪按 7.42 更新日志列出，中文名取自客户端 |
| 防御塔 | 22 | `npc_dota_tower` |
| 基地建筑 | 遗迹、泉水、兵营 | 同上 |
| 地图目标 | 前哨、赏金神符、双生之门、莲花池、智慧神龛、河道神符各 2，肉山 2，痛苦魔方 2，观察者 10 | 对应实体 |
| 禁止插眼区 | 7 块：两边泉水各 2 块、两个肉山坑、(4927, -1136) 附近一小块 | `trigger_no_wards`，按实体的转角旋转成多边形 |
| 兵线 | 6 条 | 兵营刷兵点的路径（和 7.41f 参考数据同一套推导） |

营地名不写阵营，例如“下路一塔大野”“上路边缘水生小野”；用到时按观战一方加“我方 / 敌方”。28 个营地的名字和大致位置是脚本里手写核对过的表：客户端更新后某个营地挪动超过 300 码，提取直接报错，需要人看过再改表。

相对 7.41f 参考数据移动较大的：

- 4 个营地：天辉下路高台中野 (4416, -8432) → (6712, -7632)，夜魇上路高台中野 (-4208, 8336) → (-6408, 7816)，天辉下路边缘水生小野 (2768, -8336) → (4520, -8336)，夜魇上路边缘水生小野 (-2880, 7376) → (-4228, 8140)。
- 中路一塔、二塔各移 260–370 码。

## 地点名的规则

给一个世界坐标，按观战一方（我方 / 敌方）命名，依次：

1. 在某一方三座三塔连线朝泉水那一侧（外扩 400 码）：“我方高地”“敌方高地”。
2. 在营地刷怪框里：营地名。
3. 650 码内的塔（“我方下路一塔附近”），750 码内的肉山、痛苦魔方，600 码内的其他目标（前哨、神符、莲花池等），取最近的。观察者 10 个长得一样，不用来命名。
4. 营地刷怪框外 350 码内：营地名。
5. 离兵线 900 码内：上路 / 中路 / 下路。
6. 河道附近（|x + y| < 1100）：河道。
7. 否则按对角线分“我方野区”“敌方野区”。

## 重新生成

客户端更新后：

```bash
npm run map:coach -- "C:/Steam/steamapps/common/dota 2 beta" <Source2Viewer-CLI.exe>
npm run map:coach -- "C:/Steam/steamapps/common/dota 2 beta" <Source2Viewer-CLI.exe> --check
```

Source2Viewer CLI 用 21.1，exe 的 SHA-256 必须和 `data/dota2-client-tool-pin.json` 一致（本机在 `.tmp/client-audit/vrf-21.1/`）。中间结果缓存在 `.tmp/coach-map/<build>-<hash>/`。`--check` 只比较不写文件。文件里记了客户端 build、`dota.vpk` 和实体表的 SHA-256。

`data/dota2-coach-map.json` 的 `patch` 必须是 `7.42`，教练端只认这个版本；换大版本时要重新核对营地表和地点名，再改版本检查。

## 测试

`dotnet run --project desktop/DotaCoach.TwoPc.Tests -c Release` 里的地图部分检查：营地数（6 个水生、2 个远古）、7.42 挪过的营地坐标、小地图换算、禁眼区（泉水、肉山坑）、高地的范围、地点名（高地、营地、肉山、前哨、塔、兵线、河道、野区，分我方 / 敌方），以及离开视野提醒用上了新地点名（“razor 离开视野 · 最后在我方下路一塔大野”）。
