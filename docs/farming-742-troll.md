# 7.42 巨魔战将一号位：用下一波兵决定刷哪几营

**先定回哪条线，再选沿途的野。** 这 8 局都是一号位高分排位（对局均分 7814–8270），天辉、夜魇各 3 胜 1 负。前 5 分钟只有 3/8 局出现本体野怪击杀。05:00–10:00，天辉 **4/4** 局有“下路兵→野→下路兵”，夜魇 **2/4** 局有“上路兵→野→上路兵”；另两局夜魇到 10:00 一只野也没补，不必照点离线。

## 天辉下路：一塔旁两营可正走，也可倒走

- **线在己方一塔旁，从小野往河侧走。** `9098472218`（负，15:23 才见狂战）：10:06–10:09 下路兵 ×4 → 10:17–10:22 一塔西北的小野 `good_1` ×3 → 10:31–10:36 再往东北、靠河的大野 `good_2` ×2 → 10:40–10:43 回下路补兵 ×3。**若起点在线上更靠河的一端，就倒走**：`9098402606`（胜）07:13 下路兵 → 07:30–07:34 `good_2` ×2 → 07:38–07:41 `good_1` ×2 → 07:47 回到己方一塔旁补下路兵。
- **下一波要接中线，才把短圈拉长。** `9098360852`（胜）：16:56–16:58 下路兵 ×5 → 17:04 `good_2` → 17:09 `good_1` → 17:19 向西北进 `good_15` → 17:27 下二塔北侧 `good_4` → 17:38 向西到 `good_9` → 17:43 中二塔东南的大野 `good_5` → 17:58–18:00 中路兵 ×5。这条线的出口是中路；如果还要接下路兵，就用上一条折返，不必走满六营。

## 夜魇上路：一塔南侧折返，或沿塔北外圈走

- **河侧短圈，一营或两营都能回线。** `9099209663`（胜，11:02 主栏首见狂战）：08:58 上路兵 → 09:15–09:21 己方上一塔东南、靠河的大野 `evil_1` ×3 → 09:34 上路兵，这趟只绕一营。后来一趟多打了小野：12:12–12:15 上路兵 ×3 → 12:24–12:25 `evil_1` ×2 → 12:30–12:31 折向东北的小野 `evil_2` ×3 → 12:37–12:40 回上路补兵 ×4。后一趟从离线前最后一补到回线第一补约 22 秒；兵已到就跳过第二营。
- **不走河侧，可以从塔旁往地图北边绕。** `9097559249`（胜，全局未见狂战）：12:23 上路兵 → 12:35–12:41 上一塔东北的外沿小野 `evil_11` ×3 → 13:01–13:09 向西到塔西北的 `evil_20` ×4 → 13:25–13:29 折回 `evil_11` ×3 → 14:03 再补上路兵。此局 15:12 主栏首见漩涡（8 局中仅此 1 局）；15:00–20:00 仍是本体补 **35 只兵、19 只野**，包括 19:07 下路兵 → 19:13–19:16 天辉下路小野 `good_1` ×4 → 19:22 又接下路兵。
- **前十分钟没补到野，之后也能从内侧回线。** `9098789898`（负）本体第一次补野是 12:59（`evil_2`）。后来走的是内侧回线：15:06 己方中二塔西侧 `evil_5` → 15:14 向北 `evil_4` → 15:24 向西 `evil_6` → 15:33 折西南 `evil_15` → 15:42 在上二塔以西接上路兵。是否选这条，看上路有没有能接的兵，而不是看地图上还有几个营没碰。

## 狂战与飞斧：只作时间参照

- **装备与路线事实：** 狂战斧首见于主栏的有 **7/8 局**（5 胜 2 负），中位 **13:13**，范围 **11:02–16:43**。各取首见前、后各 3 分钟，先按局计数再取中位：本体野怪 **13→30 只**，有本体击杀的不同已知营地 **3→6 个**，本体线兵 **19→14 只**。7/7 局后窗都比前窗打到更多野怪、更多不同营地，且 7/7 仍补到线兵。最晚的 `9097330939`（天辉胜，16:43）早在 13:13 就从下路兵转 `good_1`（13:18）、`good_2`（13:31），13:38 已回下路补兵。
- **技能事实：** 看录像技能栏，6/8 局在英雄 7 级首次见近、远两种旋风飞斧同为 4 级（08:08–10:49）；其余 2/8 到英雄 14 级才见 4 级：`9099283649`（17:28）、`9097559249`（21:36）。后者在飞斧未满时已走塔北外圈。
- **实战用法：** 把“扩一营后还能接到哪波兵”当作判断标准。前后窗是同局的不同时段，不能把增加的击杀都归因于狂战，也不能从技能等级断言哪只怪死于飞斧。

**读数口径：** 路线取前 20 分钟敌方线兵与中立怪的 `body` 击杀，示例对照本体 `trace`；不计幻象、反补。时刻为游戏钟向下取整秒，`×` 是只数，不代表清空一营或一波。兵线按出生路，野按出生营（ID 省略 `neutralcamp_`）；营地不明的野怪仍计只数，不计入不同营地数。装备、技能另看全局；装备时刻是逐秒快照首次在主栏（槽位 0–5）看见成品，不是购买时刻。
