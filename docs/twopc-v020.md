# 双机教练 v0.2.0：默认自动教练与 4K

> v0.3.0保留以下配置方法，但普通传输已改为持续H.264视频、教练端按需抽帧。两端必须同步升级；码流与Debug的当前行为以包内README为准。

## 使用方法（无需 E2E 脚本或 Arm）

### 教练机

1. 解压教练端 ZIP，运行 `DotaCoach.CoachClient.exe`。自带 .NET 运行时。
2. 程序默认启动接收，优先使用有网关的私有网卡地址。**核对地址确实是游戏机可达的 LAN 地址**；如选错，点击停止、改地址、再启动。`127.0.0.1` 只适合同机。
3. **自动教练、字幕、小地图目标默认开启**。默认每20秒最多一次请求、同一进程最多180次尝试（失败也计数）；可以调整，暂停会取消待返回结果并撤回提示。达到上限后明确停止，不是悄悄持续扣费。
4. 选择教练机自己的 Foundry `.env` 文件，部署名默认 `gpt-6-astra`。本机已有 `C:\g\foundry.use2.env` 时会默认使用该路径；其他电脑需要选择自己的文件。文件需包含 `AOAI_ENDPOINT`、`FOUNDRY_KEY`，**密钥不在 ZIP 内，也不传给游戏机**。
5. 界面应显示“模型配置就绪”。复制配对码给游戏端。配对码包含连接凭据，不要公开。

真实玩家画面及白名单自身GSI会被发送到指定云端，并产生API费用。这里是云端视觉＋推理，不宣称3090 Ti本地推理已启用。原有本地Ollama观察按钮仍是可选诊断工具，不需要同时运行两套视觉才能用自动教练。

### 游戏机

1. 解压游戏端 ZIP，运行 `DotaCoach.GameClient.exe`，粘贴配对码。
2. 核对 Dota 安装目录，选择“Dota 2 前台画面”，点击“连接并开始”，确认画面与云端传输说明。
3. 程序自动启动本机 GSI，并安装专用 `gamestate_integration_dota2_coach_live.cfg`。**首次安装后需重启Dota，并确保启用 `-gamestateintegration`**；普通对局不需要 `-insecure` 或作弊模式。
4. 新版 GSI 身份使用当前 Windows 用户的 DPAPI 加密保存，后续重启客户端不需要重新导出。不会覆盖用户修改过的同名配置，也不改动其他 GSI 文件。路径/权限不允许时可手动导出。
5. 进入游戏并保持 Dota 在前台。收到真实画面＋新鲜自身GSI后，普通比赛和机器人局都会自动推理，不再要求 `matchId=0` 或额外 Arm。

两端应保持同一版本。旧v0.1.2游戏端不理解新版普通对局提示类型。

## 4K：源画面、传输和标记是不同坐标系

- 读取的是**实际游戏客户区物理像素**，不是桌面分辨率、WPF逻辑像素或JPEG尺寸。3840×2160、4096×2160均可处理，分辨率改变会使旧提醒失效。
- 4K画面按比例缩小到不超过1600×900传输，元数据保留原始尺寸。字幕、圆环和箭头按游戏画面高度放大，再换算到当前显示器DPI。
- **首次请校准一次小地图**：在教练端收到真实游戏画面后，点“预览左下框”或“预览右下框”，检查蓝框是否正好覆盖小地图内部正方形。按需要调整“左 / 上 / 边长”（原始游戏像素），再点“确认小地图框”。
- 3840×2160默认布局的建议框是 `(0,1680,480)`；它只是根据旧布局比例生成的**待确认预设，不是对你实际HUD的测量**。不能因屏幕是4K就假定这个框一定正确。
- 校准按实际游戏分辨率保存，支持左右小地图及自定义尺寸。**HUD大小/左右位置变更时需重新校准**。未校准或分辨率不匹配时，字幕仍工作；地图功能保持开启，但不生成猜测坐标。
- 模型选择己方静态地标ID，程序将世界坐标投影到确认的小地图框。不能把地标阵营当作安全、有怪或有塔的证据；天辉和夜魇不会混用。

## 边界与停止

- 仅用玩家可见画面、自身GSI和带出处的历史观察；没有全图隐身敌人、读内存、自动走路、攻击、施法或队友ping。
- 普通模式不把截图/视频保存到磁盘。捕获仍是前台检查的屏幕区域采集，可能包含游戏聊天和系统遮挡，不是隔离式WGC，也不是60fps硬件编码。
- 断线、离开前台、死亡、换局/阵营/英雄、分辨率变化及原始帧过期都会撤回建议。模型失败不回退固定刷野规则，不用新帧时间给旧答案续命。
- 原始帧仍最多12秒有效。模型若耗时较长，提示可能很短或直接丢弃；没有为“看起来能用”放宽时效。
- 本次新增验证覆盖普通对局输入的自动调度、真实TLS回传、4K左右校准/投影、DPI尺寸、暂停/预算和GSI配置保护。模型使用测试替身验证调用契约；**未声称在用户的另一台4K电脑上完成真人局像素验收或证明最高GPM**。
- v0.1.2已有的三次真实模型/游戏像素E2E是1280×720本地Luna机器人局结果，不能冒充此次4K实战验收。
- 点击“自动教练”取消勾选可暂停推理；游戏端“停止/断开”停止采集；关闭两端即可结束。暂停选择会保存，重启尊重上次手动设置。

发布包是未签名便携 ZIP，不是 MSI 安装向导。配对/防火墙和模型文件属于每台机器的必要配置；程序不自动改防火墙、Steam登录或存储云端API密钥。
