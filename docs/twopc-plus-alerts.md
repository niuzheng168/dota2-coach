# 双机教练：Plus 实时观战的对手面板、离开视野和插眼提醒（教练端）

教练机用账号 B 对游戏账号做 Dota Plus 实时观战时，教练端可以把对手的情况推到游戏机上：

| 推送 | 游戏机上的样子 | 数据来源 |
|---|---|---|
| 对手等级和装备 | 游戏画面左侧一直显示的小面板：每个敌方英雄一行，头像、等级、六格装备和中立物品的图标 | 本机视觉扫描 `scripts/vision/hero_scan.py` 读到的敌方 HUD |
| 对手离开视野 | 字幕：`剃刀 离开视野 · 最后在我方下路一塔大野` | 教练端自己收到的 Plus 观战 GSI 小地图 |
| 对手插眼 | Dota 小地图上圈出可能的眼位，加一条字幕：`莉娜 少了1个假眼 · 可能在敌方上路边缘水生中野（小地图已标）` | 视觉扫描读到的敌方守卫数量变少，加上 GSI 小地图上它走过的地方和 7.42 常见眼位；规则和实测见 [`twopc-enemy-wards.md`](twopc-enemy-wards.md) |

只用观战客户端在**队伍视角**下看得到的信息：敌方只有在好友这一队的视野里时才能被选中读等级和装备，离开视野以后面板保留最后一次读到的内容，并标出是几秒（几分）前读的。延迟观战或完整观战（双方全图）不会推送任何东西。观战的对局和游戏机自身 GSI 的对局号不一致时也不推送。

对手面板和离开视野的字幕都需要 v0.4.3 游戏端：v0.4.3 起游戏端不传画面，两端要一起升级。小地图上的眼位要 v0.4.5 游戏端，更早的游戏端只显示插眼字幕。面板和字幕在游戏机上的位置、大小、透明度，以及要不要显示，在游戏端调，见 [`twopc-game-overlay.md`](twopc-game-overlay.md)。

## 使用

1. 教练端照常启动接收、和游戏机配对，并按“Plus 实时观战”折叠区配置好观战 GSI（见 `PLUS-SPECTATOR.md`）。
2. 在教练机上对游戏账号开始 Plus 实时观战。
3. 要对手面板，在教练机另开终端运行视觉扫描（准备步骤见 [`hero-scan.md`](hero-scan.md)）：
   ```bash
   .tmp/vision-tools/Scripts/python.exe -I scripts/vision/hero_scan.py scan
   ```
   扫描期间观战的 Dota 要在前台。扫描每 0.5 秒把敌方的等级和装备写到 `%LOCALAPPDATA%\DotaCoach\hero-scan\live.json`，用到的英雄头像和物品图标复制到旁边的 `icons\`。教练端每 0.5 秒读一次，游戏端每秒取一次面板（只有名字、等级和读取时间）。图标游戏端自带；它没有的（之后 Dota 版本新加的物品），向教练端要一次后就留在游戏端，`icons\` 就是给这个用的。
4. “Plus 实时观战（实验）”折叠区里有三个开关：**对手等级和装备（游戏左侧面板）**、**对手离开视野**、**对手插眼（小地图标记可能眼位）**，默认都开，设置会保存。下面显示状态：是否 Plus 队伍视角、面板推送了几名敌方英雄（没推送时写原因：视觉扫描没运行、不是队伍视角、游戏机未连接、观战的不是这一局）、小地图上标了几处可能眼位，以及最近一条字幕是否推送成功。关掉面板只开插眼时，游戏机只收到眼位，不画面板。

扫描在 Plus 队伍视角下默认只切换敌方英雄，不再读己方的装备（见 [`hero-scan.md`](hero-scan.md) 的“只扫描对手”）。

关掉面板开关、停止扫描或断开连接后，游戏机上的面板 3–5 秒内消失。离开视野的字幕时长在这个折叠区的“离开视野字幕显示”里设置（默认 3 秒）。游戏端已不传画面，见 [`twopc-status-only.md`](twopc-status-only.md)。如果在代码里重新打开视频，这个秒数回到“模型设置”，和 AI 打钱建议共用同一个字幕位置，后发的覆盖先发的。

## 规则

**对手面板**
- 每行：英雄头像、等级、六格主装备（空格显示为暗格）、中立物品，最多 5 名敌方英雄，按选手顺序。
- 装备取最近一次读取：有格子没认出来的那次读取跳过，图纸显示为空格；消耗品、守卫照常显示，和游戏里的物品栏一致。
- 读取超过 30 秒的行标出“30秒前”，超过 1 分钟的标出“N分前”并变暗。标签只在 30 秒和每满一分钟时变，游戏端只在面板内容（等级、装备、这个标签）变了时才重画。从没被看到过的敌人显示“？ 未见”。

**离开视野**
- 敌方英雄在视野里至少待了 3 秒，然后连续 3 秒不在，就提醒一次，带上最后出现的地方，按 7.42 地图命名（[`coach-map-742.md`](coach-map-742.md)）：我方或敌方高地、野怪营地（“敌方上路边缘水生中野”）、塔附近（“我方中路一塔附近”）、肉山、痛苦魔方、前哨、神符、莲花池、智慧神龛、双生之门，其余是上路、中路、下路、河道、我方或敌方野区。地图数据缺失时退回旧的粗分区。
- 视野边缘一闪而过（离开不到 3 秒又回来）不算。同一个英雄 20 秒内最多提醒一次。
- GSI 分不出被击杀和走进迷雾，在视野里被杀也会提示“离开视野”。游戏暂停时不计时。

**对手插眼**
- 同一个敌人两次读取之间守卫少了，就推测这段时间插了眼，按它这段时间出现过的位置和这一队的 7.42 常见眼位，在游戏机小地图上圈出最可能的 1–3 处，到守卫该消失时撤掉；友方看到附近的敌方守卫时也撤掉。
- 交给队友、扔掉、卖掉也算“少了”。两次读取之间敌人不在视野越久越不准，15 秒以上字幕注明“不确定”。详见 [`twopc-enemy-wards.md`](twopc-enemy-wards.md)。

几条提醒在 0.7 秒内先后到达时合成一条字幕。前一条还在显示时来了新的，会把前一条留在前面一起显示，总长超过 120 字时先丢掉最旧的。

## 实测

- **对手面板的装备**：用 15 段高分局扫描记录（含完整观战真值，共 2,869 次装备读取）回放，把所有英雄都当作敌方。每次新读取之前面板上显示的装备，和当时的真值比：每一格 98.7% 正确，一整行 7 格全对 92.2%（差的主要是两次读取之间刚买、刚换的东西，其次是达贡的等级、侦查和岗哨守卫，以及个别图标相近的物品）。曾试过“连续两次读到一致才更新”，因为跟不上购买，反而更差（每格 97.9%、整行 87.7%），所以改为显示最近一次读取。
- **离开视野**：用 2026-11-17 一局真人 Plus 观战的教练端 Debug 记录（41 分钟游戏时间）回放，按上面的规则平均每分钟约 4.6 条提醒，对线期尤其频繁。之后如果嫌多，可以把“至少待 3 秒 / 离开 3 秒 / 20 秒冷却”调大。
- **7.42 新物品**：重新提取素材后，在官方英雄试玩里把所有新商店物品和当前掉落池的 48 件中立物品放进物品栏读取，新商店物品和中立物品全对，详见 [`hero-scan.md`](hero-scan.md) 的“7.42 更新后的验证”。游戏端安装包的图标要在重新提取之后打包才含新物品；旧包缺的图标会向教练端要。
- **对手插眼**：3 场 7.42 职业比赛录像离线回放（近似视野），最可能的圈离真守卫 600 码内 42%，三个圈里最近的 600 码内 60%；敌人一直在视野里时最可能的圈 67%。见 [`twopc-enemy-wards.md`](twopc-enemy-wards.md)。
- **还没用真人 Plus 对局验证**：装备扫描都是在公开高分局的完整观战下跑的，完整观战本身不会推送。队伍视角下切换选人、只读视野内敌人的那部分，要等下一次真人局确认。

## 测试

```bash
dotnet run --project desktop/DotaCoach.TwoPc.Tests -c Release
dotnet run --project desktop/DotaCoach.TwoPc.UiTests -c Release -- .tmp/twopc-ui-<新的目录名>
.tmp/vision-tools/Scripts/python.exe -I tests/hud-vision.test.py
```

第一项检查区域命名、离开视野的计时、冷却、友方和完整观战排除、扫描文件的校验（过期、换对局、非队伍视角、旧版本、非法物品名）、图标只按 Dota 名称读小 PNG、面板的校验（最多 5 人、等级、六格、重名）、面板不续期就消失、字幕合并，以及面板、图标和提醒经真实 TLS 到达游戏端。第二项用真实教练窗口和合成的 Plus 数据，确认离开视野进了字幕、扫描的面板和图标推给了游戏机、关掉开关后面板撤回；再用真实游戏端窗口确认它取到了面板和图标。第三项检查装备读取规则，以及扫描写出的面板文件（只含敌方、按选手顺序、图标复制到 `icons\`、完整观战不写）。插眼推测和 7.42 地点名的检查分别见 [`twopc-enemy-wards.md`](twopc-enemy-wards.md) 和 [`coach-map-742.md`](coach-map-742.md)。
