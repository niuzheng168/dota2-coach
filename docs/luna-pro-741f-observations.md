## 能学习什么，不能推断什么

1. **相邻野点衔接。** 水生点之间连续处理，再转到附近陆地野点。规划应把全部可达候选、刷新后的回访和短距离衔接一起比较，不固定套一条英雄模板。
2. **向离营方向引野。** 11:32→11:38 可见怪和英雄都离开原营地中心，且怪仍存活。这要求建模攻击后摇、追逐、接敌和脱战；不能简单给每段路减 20%。
3. **技能、装备要按真实时钟传递。** 月光冷却、疯脸攻速与自我沉默在画面上可观察，不能每到新营地就恢复满蓝、刷新物品。
4. **观察兵线不等于纯打野。** 镜头会查看其他位置，随后英雄也会进入兵线附近。长周期职业发育思路和“纯野金币最大化”是两个范围，不能混算。
5. **没有观察到的策略不写成事实。** 本记录不足以确认其在该片段故意卡秒堆野、精确的 camp ID、每一次双拉、最佳目标顺序或全局最优性。
