## 发现并修复的问题

1. 地址列表默认选中了 WSL 虚拟网卡地址。同机改用 `127.0.0.1` 后实际画面和 GSI 到达。
2. `HttpClient` 超时同样会抛 `OperationCanceledException`；旧版本把它误显示为用户“已停止”。源码现已区分真实取消与网络超时。
3. 默认窗口在高 DPI 桌面上部分内容不可见。源码现已限制初始窗口尺寸并居中；已实际看到修复版教练端的视觉控件完整显示。
4. 同机切到教练窗口时，游戏端按安全设计暂停并结束旧画面会话。新增**单次延迟人工联调**：显式点击后等待5秒，再等一帧新的真实游戏画面及存活自身GSI；25秒内没有则取消。标记由人工填写归一化画面坐标，不是模型路线。没有绕过前台采集保护。
5. 本机模式不应监听所有网卡。源码已改为绑定用户选择的地址；默认 `127.0.0.1` 只监听回环，运行中锁定地址选择。跨机必须显式选择真实 LAN 地址。修复版已经重启实测，并新增实际监听地址的回归检查。

最新源码验证：**68项协议/真实TLS/GSI/视觉调用约束/延迟联调检查、27项 WPF UI 事件检查通过**。UI 新增覆盖默认回环、只绑定回环、监听时锁定地址、停止后解锁、无效延迟坐标拒绝、显式安排和清除待发提醒。教练端构建零警告、零错误；`git diff --check` 通过。
