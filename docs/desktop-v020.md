# Dota Coach Desktop v0.2.0

## 开始使用

1. 关闭旧助手，从 `/nas/share/DotaCoach-v0.2.0-win-x64.zip` **完整解压到一个新目录**，运行 `DotaCoach.Desktop.exe`。不要只拷贝 exe；`Ui/`、运行时、原生 DLL 和英雄图像都在包内。
2. 默认服务为 `https://dota2.largeniu.com/`。无需本地 Node 服务；主界面不再显示网址和两个“打开”按钮。需要自部署时，到「设置 → 高级设置」修改服务地址，切换前退出登录。
3. 登录现有账号，进入已有语音室，或粘贴房主发来的邀请链接。旧版 WebView 的登录 Cookie 不迁移；账号和房间不变。
4. 在工作台分别控制：
   - **App 内连麦**：选择麦克风，点击开启，或按住「按住说话」。说话方向在设置中选择学员/教练；房间翻译音频由原生后台播放。
   - **外部声音听译**：选择 Dota 2、YY 等程序，点击开始，在原生确认框同意后采集进程树。只返回本人可见的英文原文与中文翻译，不朗读、不发给教练。
   - **游戏悬浮字幕**：开关独立于采集；0% 顶部、50% 居中、100% 底部。支持原文/译文颜色、字号、透明度、显示器和停留时间。离线或未登录也能设置和预览。
5. 「收起到托盘」会隐藏主窗口，**继续采集**；托盘右键可显示窗口、暂停全部采集、切换字幕、退出。点窗口右上角 × 则退出并停止，不偷偷留在后台。

快捷键（若被别的软件占用，设置页会提示，托盘操作仍可用）：

| 按键 | 作用 |
| --- | --- |
| Ctrl + Shift + H | 显示 / 隐藏字幕 |
| Ctrl + Shift + L | 停止外部监听 |
| Ctrl + Shift + M | 关闭麦克风 |

快捷键不会自动打开录音。麦克风暂未提供软件回声消除，**建议佩戴耳机**，避免扬声器译音进入麦克风。游戏建议无边框窗口，独占全屏不保证覆盖。

## 这次实际重构了什么

```text
随包发布的 HTML / CSS / JS（不请求线上网页）
    ↕ 本地白名单控制指令、状态、字幕
C# DesktopSession（生命周期、房间、鉴权、内存聊天记录）
    ├─ NativeMicrophone → NativeVoiceChannel → 既有语音 WebSocket
    ├─ ProcessLoopback → NativeVoiceChannel → 私有监听 WebSocket
    ├─ NativePlayback ← App 房间译音
    └─ SubtitleWindow ← 对话原文/译文
```

- `ServiceClient` 持有服务端 Cookie/CSRF，HTTP 与 WebSocket 均在 C# 中建立。Cookie/CSRF 不暴露给渲染器；账号密码不写入磁盘，关闭 App 后需重新登录。
- PCM **不再以 Base64 发送到网页**，网页也不创建音频 WebSocket、麦克风流或播放音频。采集线程通过有上限的原生发送队列直接上传。
- 导航「工作台 / 对话 / 字幕 / 设置」仅切换本地视图，不改变音频会话。正常本地页面重载从 C# 状态恢复；渲染进程异常则明确暂停采集，避免界面失控后继续录音。
- 外部监听仍必须收到服务端 `listener.config` 私有/文字协议确认才开始采音。队列积压、网络中断、无上传确认或撤权时停止，不自动重新录音。
- 字幕定位逻辑直接包含在桌面包，不再依赖线上网页版本；**v0.2.0 不需要先上线之前待发布的 v0.1.3 网页**。后端兼容已部署的 `listener-v0.1.2-20261114-r2` API/私有监听协议。
- 聊天记录由原生会话暂存，页面切换/正常重载不丢；离开房间/退出登录清空，最多 300 条，不在磁盘保存。
- 界面无需联网即可打开；登录、房间、转录、翻译仍需服务可用和网络连接。不包含离线翻译模型。

## 界面与功能

- 深色工作台：独立连麦/监听卡片、音量表、上传确认/字幕阶段、实时双语对话、字幕预览、阵容快捷入口。
- 独立「实时对话」「悬浮字幕」「设置」页面，不在主操作区堆叠模型和服务选项。
- 房间管理支持新建、邀请、允许名单、角色、自身译音监听、引擎/音色/ASR、重连和离开。
- 本地随包提供 127 英雄目录/头像，可搜索外号、选最多 10 人；可下载 GSI 配置。自动 GSI 更新仍由既有后端推送。
- **窗口视觉识阵暂留在网页版高级工具**，设置页提供入口；系统浏览器独立登录。桌面端本次不宣称完成了这一功能的原生迁移。
- 可导出诊断 JSON，仅含版本、系统版本、服务主机名、连接状态、采集状态和帧数；不含录音、聊天、账号 Cookie、房间号或邀请。

## 安全与限制

- WebView2 仅映射包内 `Ui/` 到 `https://dota-coach.local/index.html`，不把整个程序目录暴露给网页。导航/新窗口/下载受限，网页麦克风、摄像头等权限全部拒绝。
- 只有本地入口文档能发送原生命令；远程站点不能访问桥。CSP 禁止远程脚本、frame 和对象；前端仅用 `fetch` 读取本地英雄目录。
- C# 命令有白名单；页面不能传任意请求 URL、文件路径或命令执行参数。服务端保持现有账号、邀请与房间校验；不绕过证书错误。
- 停止/关闭/撤权会释放采集并丢弃排队帧。没有全系统录音兜底，没有游戏注入、内存读取或驱动安装。
- 仍然采集目标程序的混合输出，游戏台词/音乐/其他说话人可能影响识别，不能保证只提取教练或完全过滤非英语。
- 当前是 **未签名便携测试包**，不是带签名的 MSI/MSIX；自动更新、安装卸载向导、字幕拖动编辑、语音分离等没有包含在本次交付。不要将 ZIP 打包成功等同于这些功能已完成。

本地配置为 `%LOCALAPPDATA%\DotaCoach\overlay.json` 和 `connected-server.txt`；新的 WebView 资料目录为 `DesktopWebView`。没有复制旧浏览器 Cookie。

## 构建与验证

```powershell
./desktop/build.ps1
```

脚本读取 csproj 的 `0.2.0` 版本，生成版本化 ZIP / SHA256 并复制到 `/nas/share`。Windows 开发机可用 `-ShareDirectory` 指向同一 NAS 的映射盘/UNC 路径。已存在同版本包时拒绝覆盖。

```bash
npm run typecheck
npm test
dotnet build desktop/DotaCoach.Desktop -c Release
dotnet run --project desktop/DotaCoach.CoreTests -c Release
DOTNET=/path/to/dotnet node tests/native-transport.mjs
node tests/desktop-workspace.browser.mjs
```

浏览器脚本支持 `PLAYWRIGHT_MODULE` / `PLAYWRIGHT_EXECUTABLE_PATH`。新增验证：

- **真实 .NET HTTP/WSS** 对接临时 Node 服务（翻译引擎模拟），验证账号鉴权、CSRF、双通道 PCM、监听隐私/无 TTS、撤权、取消启动、旧服务器拒绝。没有生产账号或云模型调用。
- **真实 Chromium + 模拟原生桥** 验证本地界面、离线预览、登录房间、双通道控制、页面切换不停止、字幕设置、英雄选择、邀请、PTT 快速松开、1000px 布局、退出清理。
- 核心 C# 断言验证原生窗口定位/DPI、可信本地来源、协议、设置归一化与有界会话记录。
- 仍需 Win11 实机验收：麦克风录音与译音播放、Dota 2/YY 进程采集、托盘与全局快捷键、多屏缩放、长时间游戏运行、实际音频设备切换。Linux 编译/模拟测试不能替代这些项目。
