## 证据与复算

- 版本与身份：官方补丁起止、OpenDota 补丁 61/开局/阵营/英雄/胜负/时长、可见账号、逐版 `steam.inf`，以及十人终局正补。每个成功 ID 都重新核对压缩回放、DEM 和元数据 SHA-256；与 facts 的 DEM 哈希相符并不认证 HTTP 传输。

- 原 16 用全量 facts；新 `route-core` 普通秒帧只需目标英雄，终局仍核十人，均验证相同 28 个野点、22 座塔。共用 `study-742.ts` 的同 tick/单位名归属，不猜最近野点，不合并同 tick 的多个死者。`events` 保留本体、幻象、未知及未定位事件；`firstHeld` 是全局主栏首见，不是购买时间。

- `points` 只含真正到达的 5/10/15/20 分钟首帧（延迟 <1.2 秒）。`startPoint` 是首个非负游戏时刻；`endPoint` 是终局，不冒充整点。经济含受控单位；事件窗左闭右开，研究最多到 20 分钟。

- 路线：5–20 分钟本体 `trace` 约每 2 游戏秒采样；0–5 只有事件和经济，不画连线。要求存活样本距事件 ≤1.05 秒、距死点 ≤1000 地图单位，野怪还须距出生点 ≤1000。只考虑本体；幻象忽略，身份/出身/死点不明或同 tick 有多种地点则断链。相邻击杀间隔 ≤30 秒，不跨轨迹中断、死亡或时间窗；合并同地连续击杀，三站跨度 ≤90 秒。读的是击杀顺序，不是两站之间走过的每一步。
