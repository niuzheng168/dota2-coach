# 7.42 实际地形与步行时间：露娜、巨魔战将

**用的是实际 7.42 客户端地图，不是旧图、击杀连线或录像拟合的导航。** 估时为**静态模型允许的折线路长 ÷ 该段英雄有效移速**。它回答“如果现在只往那里走，大致要多久”，不回答“打完下一营要多久”，也不保证客户端会选同一路。不能走或没有有效移速就不报时间。

**移速必须由调用者提供。** 此 build 的英雄 KV 基础值是露娜 325、巨魔 290；假腿字段为远程 +45、近战 +55。例如只穿假腿、无其他移速效果的露娜取 370，远程巨魔取 335。不要把这两个数当成整场常数：巨魔姿态和被动等级、主动相位/疯脸、减速、方向性水流等都可能改变读数。地图有 **8 条、154 个控制节点**的移速曲线，原点、角度、节点、半径和类型都已保存；**没有**把控制点当成精确生效边界，也没有统一乘一个河道倍率。若只知道当前有效速度，本次结果是“该速度保持不变”的条件估计；已知中途改变时，应按实际分段路长分别除以当段速度。录像的 `m_iMoveSpeed` 只是基础字段。

### 什么叫“模型允许”

1. 保留 GNV 原始标志；在开格上叠加静态树、缺地面/突出的 clip、**74 个**塔、兵营、基地、门、莲花池等实体的预留区域。树按 32 单位预留圆碰到的格子封闭；结构依据当前 KV 的 hull **类别**，采用保守预留半径：小 48、填充类 144、塔类 160、基地/兵营/无类别阻挡器 320。这些是**建模余量**，不是本 build 引擎测得的精确碰撞半径。覆盖优先级去重后，格心尚有 **47,275** 个开放。
2. 8 邻接 A*：不斜穿阻挡格的角；相邻格心高度差大于水平步长就不连，防止从悬崖正面上去。按**水平**里程计时，高度是通行约束，不把坡面斜长混入英雄 XY 移速。
3. 起点终点保留实际坐标，不吸附到最近开格。所有端点连接和折线简化都逐格遍历，并用半宽 24 的水平包络对阻挡格做**整个线段**的扫掠检查，不只检查折点。28 个营地中心的 **756 个有向组合均可达，其中 752 个不能直达**；所有返回的折线段反向也通过同一包络检查。输出是该静态近似中的一条通路，不声称是引擎寻路结果或连续空间最短路。
4. 不推测砍树/长树、拆塔时间、单位拥堵、转身/起停、施法、走位目的；不跨门传送，不把闪烁、飞行、穿树、位移技能当步行。无路径或端点受阻时返回具体原因，**不退回直线**。也不把通行性当作安全性。

## 三场独立留出：误差与不能回答的部分

**地图只从 VPK 构建，未用录像轨迹开格、学路线或拟合速度倍率。** 从现有研究中取**全部 3 场 build 6989 对局**作留出：两场夜魇巨魔、一场天辉露娜。逐 DEM 核 SHA256、实际 server build、终局和真实玩家选中的本体句柄。按网络实体提取约 0.133 秒间隔的 XYZ、存活、移动标志和基础速度；用暂停感知的游戏时钟。删除重复游戏时间的 259 次观测，暂停前后不当成连续行走。

**形状检查，5–20 分钟。** 19,619 个存活坐标全部落在原始 GNV 开格，**18,792（95.78%）**满足更严格的静态包络。余下 827 点：251 在站树预留格，223 在结构预留格，353 的中心格是开的但英雄包络碰到邻格。没有为了让轨迹全过而删树或开格。格心 PHYS 高程与该格内英雄网络原点 Z 的绝对差：均值 **0.666**、中位数 **0**、P99 **13.563**、最大 **349.781**，29 点超过 32 单位。这是在不同 XY 位置比较格心和英雄原点，不是对整个高度图、连续碰撞或空中状态的精确证明。

**时间检查。** 自动取连续存活且移动标志为真的步行段：采样间隔 80–200 ms、步速 120–650 单位/秒，断流、死亡、突跳和停步切断。每段最前至少 1.2 秒的实走里程与时间**只用来估计出发时有效速度**，不包含随后被评分的坐标；评估其后 2–10 秒。长段分割、不重叠使用未来标签。输入是真实起终点，不预知玩家中间怎样走；不是对目的地的预测。分位数用最近排名法。

| 留出样本 | 可估 / 符合步行段筛选 | 平均绝对误差 | P90 绝对误差 | 最大绝对误差 |
|---|---:|---:|---:|---:|
| `9099209663` 夜魇巨魔 | 39 / 44 | 0.475 s | 1.621 s | 2.479 s |
| `9099283649` 夜魇巨魔 | 46 / 49 | 0.495 s | 1.859 s | 3.868 s |
| `9100049738` 天辉露娜 | 52 / 54 | 0.683 s | 1.923 s | 6.697 s |
| **合计** | **137 / 147** | **0.561 s** | **1.859 s** | **6.697 s** |

- 另外 **5 个起点、5 个终点**被静态包络拒绝，未算成零误差。137 段实走时长中位 **4 秒**，误差中位 **0.173 秒**，平均有符号误差（估计 − 实走）**−0.367 秒**。其中 **105 段直线不能走**：可行路线 MAE **0.544 秒**；仅作反例的弦长除移速 MAE **0.794 秒**。15 段的随后实走平均速度与前缀相差超过 10%。
- 两端可达不等于复原了职业玩家每一步：137 段中只有 **55 段**的整条观测折线也通过同一静态包络。玩家可以走另一条路，树/建筑状态也会变，保守包络还会错拒；不把其余 82 段称为“玩家走得不合法”。
- 一个农区实走例子：露娜 `9100049738` **15:36.600–15:44.333**，从 `good_1` 附近到 `good_20` 附近。本段前缀推得移速 **406.65**（基础字段仍是 325）；模型 **7.913 s**，实走 **7.733 s**。这是英雄坐标，不是中心到中心或两次击杀之差。两端均在不同营地中心 600 单位内的独立片段**仅 3 段**，不足以承诺每一对营地都有同精度。
- 反例：同场 **7:43.533–7:53.533**，英雄实际绕行约 **3,630** 单位，端点只隔 **969**，模型允许的路线长 **1,119**。预测 **3.303 s** 对实走 **10.000 s**，低估 **6.697 s**；录像并未说明玩家为什么绕路。
- **不挑未来是否在走的对照**：每 10 秒固定取一个窗口，交替预测 3/5/7 秒后的真实端点，共 270 个。182 个缺可用的出发移速前缀，4 个死亡/间断/突跳，7 个端点被拒。余下连续步行 9 个，MAE **0.440 s**；混有停步、转向或其他非连续移动的 68 个，MAE **2.304 s**、P90 **4.382 s**。**不能把步行 ETA 当作进出野区、清野、接下一波线的总时间。**

## 查询与复现

本仓库根目录、Node 24；前四条不需游戏、网络或 DEM：

```powershell
node scripts/client/terrain-742-query.ts --camp good_14 good_20 370
node scripts/client/terrain-742-query.ts --xy 4520 -8336 6712 -7632 370
node scripts/client/terrain-742-validation.ts --check
node --test tests/terrain-742.test.ts
```

程序接口是 [`estimateWalk742(from, to, effectiveMoveSpeed)`](../src/tactics/terrain-742.ts)。成功返回 `points / distance / seconds`；失败返回 `ok:false` 和 `reason`。没有默认移速或“最近可达点”替代值。它是独立的离线模块，没有改动旧规划器。

从实际资源复建：

```powershell
# 固定安装和 CLI 的默认路径；亦可在 --check 前显式传入两个路径
node scripts/client/terrain-742-extract.ts --check

# 本机已有的三份原始 DEM；重新读至终局，不启动游戏
foreach ($id in 9099209663,9099283649,9100049738) {
  .tmp/replay-tools/Scripts/python.exe -B scripts/client/terrain-742-replay.py $id
}
node scripts/client/terrain-742-validation.ts --from-captures --check
```

发布数据合计 **169,981 字节（约 166 KiB）**：[地图包](../data/farming-742-terrain.json)内含可逐字节复原的 GNV、TRM、分层实体树高、物理地面格、clip 标志、营地和移速原始控制数据；[留出轨迹](../data/farming-742-terrain-traces.json)内含带 SHA256 的压缩差分记录；[误差报告](../data/farming-742-terrain-validation.json)能由前两者与原研究的比赛版本清单离线重算。高程和树实体 Z 以小端 int16 保存，除以 4 得世界单位，`−32768` 是未知而非地面。完整 VPK、提取中间文件和 `.dem` 不随数据分发。

交付时仓库 TypeScript 检查、9 项新版地形测试及 17 项相关历史地图/7.42 录像回归均通过；从本机 VPK 重提和从三份 DEM 捕获复算均与发布数据相符。没有运行实战教练，也没有把这些结果当作全游戏物理认证。
