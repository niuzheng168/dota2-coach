### 用同一组假设把走路、接敌、清营接起来

假设天辉露娜 10:10 从 `good_1` 出发，玩家**确认** `good_2` 是满血大人马一只、小人马两只。有效移速 370，面板攻击 110–116、总攻速 180，三级月刃，三个目标互相可弹且为这个示例取零弹道延时。指定攻击位置就取 `good_2` 中心，另假设到达至首次命中 **0.55 秒**；这些是假设，不是对该分钟全图野怪状态的推断。

| 组成部分 | 模型输出 |
|---|---:|
| 从起点到指定攻击位置 | 可走路径 1614 单位，约 **4.36 秒** |
| 第一下已经命中 → 三只全死 | **8.50–9.44 秒** |
| 出发 → 全死（加上给定的 0.55 秒） | **13.41–14.36 秒**，该档列出的整营毛赏金 **81–93** |

```powershell
node scripts/client/farm-742-segment.ts data/farming-742-segment-example.json
```

可以复制示例修改属性、姿态、可覆盖的副目标、起终点或移速。不给接敌延时，就不报合并倒计时；没有可走路径不会用直线补猜。另一例：天辉南缘的小水野 `good_14` 到原门高台中野 `good_20`，两点的直线被挡；移速 370 时，纯步行估 **6.74 秒**，不含清野。

**误差分开看。** 在三场同 build 的留出录像里，137 段可估的 2–10 秒连续步行，平均绝对误差 0.56 秒，P90 为 1.86 秒，另 10 段拒估。16 场中按出生实体、英雄首伤、最后一只死亡识别出 368 段清营，但仅 **25 段**满足模型直接比较条件（露娜 23、巨魔 2）。模型中点的绝对误差中位为 **0.86 秒**；真实耗时只有 **3/25** 落在模型列的情景区间内。该区间描述理想攻击条件，不是实战预测区间。相反，对能按同一成长档报价的 364 段，**364/364** 的整组毛赏金上下限都与回放实体字段一致；这也不是最终进钱包的净额。

### 如何看候选、何时该沉默

在本机先试不连接游戏的演练：

```powershell
node scripts/farm-shadow-bridge.ts --demo
```

普通玩家 GSI 提供的是**本体**的英雄、位置、物品、血蓝等数据，不是敌人和营地雷达。比如你确认了“下路有兵”和“一塔小野为空”，回放里有人打过小野也不会让本次把空营列为可选。上一次目击过期、看到危险、暂停、死亡或换局都撤回。GSI 不足以独立认证子版本，真实自定义局需按手册确认匹配的 build 和本人视角。

在留出分析里，下一次本体正补属于兵线还是己方营地，是**标签**而非让模型偷看的输入。逐场滚动只用此前已结束的不同账号录像，宽类预测只覆盖 **72/464** 个窗口。在模型和基线都有预测且实际类别明确的 **54** 窗里，命中 **29 vs 26**；最新 4 场的固定留出只剩 **2** 个这样的可比窗口。不足以断定模型比简单基线好。没有真实玩家视野标注时，不能报告“玩家当时看到并能执行”的命中率。

### 补齐空间数据

85 个新候选首次索取 OpenDota 回放地址时遇到 65 次 520、20 次超时。重复探测时旧对局也失败，并非证明 Valve 已删除这些录像。另查了这 **85/85** 场 D2PT 公开详情：均无可用的 `playback` 字段或直接 DEM 地址，本机逐页状态和页面哈希在 `.tmp/farm742-more/d2pt-match-fallback.json`。[逐场审计](../data/farming-742-expanded-audit.json)保留候选和原因。**不猜下载盐、不读取 Steam 账号、不把缺录像的对局填成模拟轨迹**。接口恢复后，可在工作区显式重试：

```powershell
node scripts/replays/collect-expanded-742.ts
node scripts/replays/pack-expanded-742.ts --partial
```

重试先探测一场；服务未恢复就中止，不重复请求整批。`--partial` 只在 `.tmp` 生成预览；核验并封存新发布档的步骤见[扩展研究](farming-742-expanded.md)。如果能提供名册中缺失比赛的原始 `.dem` 或 `.dem.bz2`，不必提供任何账号密码。
