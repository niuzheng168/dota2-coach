# 7.42 一号位打钱路线：露娜与巨魔战将

更新：[101 场发育节奏、新地图与影子教练](farming-742-field-guide.md)。下文仍是原 16 场可定位回放，不将只有分钟数据的比赛算作路线。

**结论：露娜较早把几个营地串在两波线之间；巨魔前段更依赖兵线，起手用一塔旁的一两个营地补空档。** 两者都不是到某分钟就弃线钻野。下面是 16 场 Dota2ProTracker 高分排位的实录，不是把 7.41f 的路线画到新地图上。

## 先认新地标

7.42 把双生之门移到地图的上下边缘；两端的小水野向水流末端移动，附近的陆地中野上了**原双生门高台**。优势路一塔旁的小野、大野刷新框也缩小了。**“门旁中野”和“原门高台中野”不再是同一条指路说明**，旧版拉野站位、秒数也不要照搬。

| 看哪一侧 | 一塔内侧的普通野 | 水流末端的小水野 | 原双生门高台的陆地中野 |
|---|---|---|---|
| 天辉下路 | 小 `good_1`、大 `good_2` | `good_14`，南沿偏东 | `good_20`，比小水野更靠东 |
| 夜魇上路 | 小 `evil_2`、大 `evil_1` | `evil_11`，北沿偏西 | `evil_20`，比小水野更靠西 |

这些是本批回放的出生器编号，不是地图上的安全区；“小水野”指初始档位。四个移动营地的新坐标均从回放读取，未借用旧底图。

| 英雄、阵营 | 回放里实际怎么走 | 可以学什么 |
|---|---|---|
| **天辉露娜** · [Quinn，9097587313，败](https://dota2protracker.com/matches/9097587313) | **10:30 小水野 → 10:42 原门高台中野 → 10:52 下路线**。12:44 从高台反向打，12:51 小水野 → 13:04 一塔内侧小野 → 13:13 下路线。 | 新版南沿两点可以双向衔接。先看下一波线的位置，再决定是否多打一营；不需要每圈固定同一方向。 |

**实战取舍（建议，不是录像事实）：** 露娜先问“打完这两营，哪一条线正好进来？”；巨魔先问“下一波线到之前，我来得及打几营？”。线已被队友收走、营地没怪，或下一营要越过没视野的位置时，缩短这一圈。样本里有人跨边或进对面野区，不意味着自己这一局也安全。

## 两个英雄的差异有多大？

每项先逐场计算，再在各自 8 场内取中位数。“线占比”是录像的**小兵类金币 ÷（小兵类＋野怪类金币）**，不是纯兵线赏金占比。两项按游戏计数器分类：例如 `9097037811` 击杀小蜘蛛给前者记了 9 金，击杀中立召唤骷髅给后者记了 5 金。“野点数”则只数该窗口有**本体、可定位击杀**的不同出生器；打到一只就计入，不是清空次数。

| 时段 | 露娜：线占比 / 野点数 | 巨魔：线占比 / 野点数 |
|---|---:|---:|
| 5–10 分钟 | 63.9% / 4.5 | 82.3% / 2.5 |
| 10–15 分钟 | 41.5% / 9.5 | 63.5% / 5 |
| 15–20 分钟 | 42.0% / 11 | 48.1% / 7.5 |
| **10–20 分钟合计** | **41.1% / 13.5** | **54.8% / 9.5** |

- 10–20 分钟，**16/16** 都有敌方线上小兵及野怪的击杀记录。两类金币合计的每分钟中位数为**露娜 548.1、巨魔 461.1**；并非总 GPM、保底收益或英雄强弱结论。10 / 15 / 20 分钟累计正补中位数分别是 **69.5 / 142 / 232.5** 和 **54.5 / 116.5 / 185**。
- 露娜本体打到两侧常规远古营（`good_8`、`evil_8` 任一处）的局数，按上述三个五分钟窗口依次是 **0/8 → 5/8 → 7/8**。这是能定位到出生营的击杀，不包括水野后来升级的情形，也不是看时间就必须去的任务。
- 露娜 **7/8** 在主物品栏出现过疯脸，**8/8** 出现过分身斧，但只有 **5/8** 在 20 分钟前持有分身斧。10–20 分钟只有 **4/8** 记录到友方露娜幻象击杀敌方兵线单位；不能把所有线上金币都画成本体走过的路，也不把全部幻象归因为分身斧。
- 巨魔 **7/8** 在主物品栏持有过狂战斧，这 7 场的首次观测中位数约 **13:13**。分别比较每局首见前、后各三分钟，本体有击杀的不同营地数中位由 **3 增到 6**，后窗 **7/7 仍有线补**。不是装备单独造成增幅的证明。另 1 场 `9097559249` 走电锤路线（15:12 见漩涡），10–20 分钟是 **2741 小兵类金币、669 野怪类金币**。

逐英雄的样本频次、两边的走法和反例见[露娜细读](farming-742-luna.md)、[巨魔细读](farming-742-troll.md)。

## 取样与核验

- **2026-11-22 UTC 采集**。[Valve 7.42 更新](https://www.dota2.com/patches/7.42)及[官方补丁列表](https://www.dota2.com/datafeed/patchnoteslist?language=english)已核对。样本开始于 **2026-11-19 15:00 至 11-21 19:10 UTC**，均在新版上线后。
- 来源是 D2PT 的 [Luna](https://dota2protracker.com/hero/Luna?section=matches) 和 [Troll Warlord](https://dota2protracker.com/hero/Troll%20Warlord?section=matches) 的 Matches 表数据。不能按网页标题认版本：实际目录还混有 **28 条 7.41f 赛事记录**。逐行限定 `patch=7.42`、`position=pos 1`、`lobby_type=7`，分别剩 **81 / 44** 场。限定对局平均 MMR ≥7500 后，候选为 **29 / 13** 场。
- 各英雄在天辉、夜魇各选**对局平均 MMR 最高的 4 个不同账号**（同分取较大 match ID）；未按胜负、装备、收入、时长选取。入选露娜 **7843–8335 MMR**、巨魔 **7814–8270 MMR**；两组均 6 胜 2 负。跨阵营允许相同账号，分别对应 6、7 个不同账号。是小样本高分排位，不是 16 名职业选手，不代表总体出装率或胜率。
- OpenDota 只提供交叉核对和 Valve 回放地址。逐场验证：英雄、账号、阵营相符，`patch=61`（7.42）；解压散列与实际解析文件一致，所有回放解析至终局，**16 场 × 10 人的终局正补全部与 OpenDota 对上**。回放 build 为 6983、6985、6986、6988、6989；对应 `steam.inf` 提交、日期、哈希已固定。
- 16 场均覆盖至 20 分钟，且**28 个营地与 22 座塔**的取整地图几何一致。中立单位死亡按**同 tick、同单位名、唯一出生器归属**关联，不采用“英雄靠哪个野点最近”。10–20 分钟共 **1427** 条中立击杀（含幻象），其中 **88** 条无法消歧到营地，留作未知。敌我兵线区分，排除反补；线别取小兵出生地，落点单独记录。金币来自队伍对该玩家的累计计数，包含受控单位；不从击杀数倒推金币。

### 如何复核

小文件 [逐场坐标、经济、击杀和来源](../data/farming-742-routes.json) 包含 16 个 D2PT 对局链接、候选排名、地图地标、20 分钟内的逐条线野击杀、5–20 分钟本体轨迹。无需安装游戏或下载回放即可复算上表：

```powershell
node scripts/replays/study-742.ts --summary
```

本机 `.tmp/farm742/` 另存了两个原始 D2PT JSON 目录、官方补丁快照、build 记录、每局 OpenDota metadata、压缩回放、DEM 与完整 `facts.json`。从原始证据重新核对整个展示文件：

```powershell
node scripts/replays/study-742.ts --check
```

若只需重取某场，使用新的空目录，避免覆盖证据：

```powershell
node scripts/replays/download.ts 9098402606 .tmp/recheck-742
.tmp/replay-tools/Scripts/python.exe scripts/replays/decompress.py 9098402606 --root .tmp/recheck-742
.tmp/replay-tools/Scripts/python.exe scripts/replays/extract.py 9098402606 --root .tmp/recheck-742 --hero troll_warlord
```

露娜用 `--hero luna`。公开回放下载地址可能过期；已发布的研究数据不依赖实时请求。不向实战教练接入回放全图信息，也没有覆盖 7.41f 的历史样本。
