## 运行与操作

```powershell
npm run sandbox
# 默认本机 127.0.0.1:3221；用启动日志中的会话地址
npm run typecheck
npm test
```

- **播放 / 暂停**：1×、5×、20×；底层仍为 200ms 固定步长。
- **单帧 +200ms / 推进10秒**：暂停时也能用。
- **时间轴**：任意拖到过去/未来。生成未来使用同一确定性世界，不播放另一份录像。
- **添加 Luna**：默认加入本方下野区附近经网格验证的位置；也可“在地图放置”自行选点。等级 1–30 可选。
- **装备**：先选物品再点“装备”；点击栏位移除。假腿可切力量/敏捷/智力，主动疯脸带冷却/蓝耗/沉默/移速/攻速/减甲。
- **左键**选单位，**右键**移动或攻击；也可用“场上单位”下拉菜单选目标，再点攻击。月光仅作为额外伤害测试。
- **滚轮/＋/−**缩放，**中键拖动**平移，“全图”恢复，“跟到英雄”定位。
- **回退后操作**明确建立新分支并舍弃原未来，不把后来装备/金币带回早期帧。
- **无英雄重置**重建该种子的环境并清空英雄、金币、时间轴命令。

页面与 API 无云模型调用、不进入 Dota 匹配、不控制游戏客户端。
装备属于场景编辑，**不扣游戏购置费**；金币只用于验证击杀收入，而不是做尚未实现的商店经济。

## 实现文件与 API

- `src/simulation/data.ts`：核验地图、可用物品、通行点与限制。
- `src/simulation/stats.ts`：装备/等级→实际属性，输入校验。
- `src/simulation/world.ts`：兵、塔、野怪、英雄、攻击与逐单位金币。
- `src/simulation/timeline.ts`：每 25 帧检查点、命令重放、分支与版本号。
- `public/simulator.html/css/js`：可操作地图、朝向、装备、属性和时间轴。

API 使用原本机沙盒 token、Host/Origin 防护，不放宽访问权限：

| 接口 | 行为 |
|---|---|
| `GET /api/sim/context` | 地图、注册英雄、装备目录、默认可放置点与限制 |
| `GET /api/sim/state` | 当前完整显示状态、帧、金币、事件、版本 |
| `POST /api/sim/reset` | 指定种子的新无英雄场景 |
| `POST /api/sim/advance` `{ticks}` | 1–50 个整数帧 |
| `POST /api/sim/seek` `{tick}` | 0–3000 的目标整数帧 |
| `POST /api/sim/command` `{command}` | 加入/移除英雄、移动/攻击、装备、主动 |

POST 可传 `revision` 拒绝来自旧画面的命令；重置也递增版本。
修改失败不会清空未来或改变 RNG/金币。检查点、命令、弹道、冷却和 RNG 一并恢复。

后续扩展英雄需注册基础数据及特有技能适配；不需要重写时间轴、兵塔 AI、金币或通用装备系统。
当前页面**只开放 Luna**，没有假称所有英雄已支持。

## 仍然是简化模拟，不是完整客户端复刻

本次完成用户列出的交互验收项，不意味着此前完整物理校准的所有缺口已消失：

- 没有完整的战争迷雾、复杂拉仇恨、反补、护甲攻击类别、塔保护、闪避、高低坡、全部英雄技能。
- 普攻前摇与弹道按 200ms 量化；暴击采用可复现独立随机，不是客户端伪随机分布。
- 野怪普通组合按种子生成，水生进化/技能未完整复刻；不会据此报告实战 GPM。
- 使用初始树状态；自然长树/动态水流、单位挤碰和完整转身机制未复刻。
- 塔死亡显示和停止攻击已实现；导航中的原始塔障碍保留到场景重置，尚无动态网格重建。
- 月刃级数随场景等级预设；月光是即时伤害测试，没有眩晕/施法前摇。未开放完整加点树。
- 英雄等级由场景选择，不自动升级、购买、复活；自由编辑装备不是游戏中的购买行为。

这些限制公开在页面，不将模型规划换成硬编码刷钱路线。当前只是执行明确操作的机制世界，
原先实战路线建议开关仍关闭。

## 野点状态、刷新与收益标记（2026-11-15 增补）

以下是初版记录；常驻标签的展示方式已被下一节的悬停交互替代，数据含义不变。

- 全图 28 个野点均显示标签：**有怪 × 数量 / 空**；空野点显示下次检查的倒计时；
  标签下方显示**可得金币**或**下一组预计金币**。标签引线仍指向核验坐标，不移动真实野点。
- 点击标签或“选择野点”查看刷新框、绝对检查时间、金币区间、占框说明。
  可开关“野点收益”图层；窄屏增加标签空间，地图坐标保持等比例，不拉伸地图。
- `GET /api/sim/state` 的 `camps` 数组来自当前世界，不另造计时器：
  `hasNeutrals / aliveCount / outsideCount / spawnBlocked / blockerIds /
  nextSpawnTick / nextSpawnTime / secondsUntilSpawn / currentGold / nextSpawnGold`。
- 每 300 帧（60 秒）检查一次；`59.8s → 0.2s`，检查帧执行后显示下一分钟。
  倒计时随暂停停住，随时间轴还原，不使用电脑时钟。
- **有怪 ≠ 占框**：拉出框外的所属活怪仍计数量和金币；空框内的英雄/小兵/其他营地野怪也可能阻止刷新。
  状态显示与实际生成共享同一 `campBlockers` 判定。死亡单位既不阻挡，也不计剩余收益。
- 当前可得金币是活怪已生成的模拟赏金总和，不随血量比例折减，也不会自动计入英雄收入。
  清掉全部野怪才显示为空；英雄实际击杀结算仍由原战斗层处理。
- 下一组金币取本模拟器同类组合**等概率**均值和最小/最大区间；使用与生成单位相同的金币定义，
