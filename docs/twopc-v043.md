# 双机教练 v0.4.3：使用说明（游戏端不再传画面）

v0.4.3 起游戏端不再把 Dota 画面传给教练端：

- 对手的等级和装备由教练机 Plus 实时观战读取，显示在游戏机画面左侧的对手面板里。
- 补刀看游戏端自己在血条上方画的小兵血量数字。
- 依赖画面的 AI 自动教练（打钱路线）和小地图校准停用；代码保留，见 `NO-VIDEO.md`。

**两端都要用 v0.4.3**：v0.4.2 和 v0.4.3 不能混用。升级后重新复制配对码。

## 新内容

| 功能 | 说明 | 包内说明 |
|---|---|---|
| 小兵血量数字 | 游戏端在每根普通兵血条上方显示当前血量，友方绿字、敌方白字。只在游戏机显卡上识别和绘制，不需要连接教练端；显卡有余量时每帧刷新，被游戏占满时限 60 帧/秒 | `CREEP-HP.md` |
| 对手面板、离开视野字幕 | 教练机 Plus 实时观战时推送：敌方英雄的等级和装备（需在教练机运行视觉扫描），以及敌方离开己方视野的字幕。只用队伍视角看得到的信息 | `PLUS-ALERTS.md` |
| 游戏内显示设置 | 游戏端可以隐藏、移动、缩放字幕和对手面板，改颜色和透明度，并在 Dota 上预览 8 秒；设置只存在游戏机本地 | `GAME-OVERLAY.md` |
| 不传画面 | 游戏端只发自身 GSI 和 Dota 窗口尺寸（每 0.25 秒一条），用来保持连接、接收字幕和对手面板 | `NO-VIDEO.md` |

## 教练机

1. 解压教练端 ZIP，运行 `DotaCoach.CoachClient.exe`。程序启动后自动开始接收。
2. 核对“本机地址”：跨机必须是游戏机能访问的局域网 IP，不要选 WSL 虚拟网卡；`127.0.0.1` 只用于同机。要改地址，先点“停止接收”，改好再点“启动接收”。
3. 点“复制配对码”，私下传到游戏机。配对码含连接密钥；怀疑泄露时点“撤销配对”，再重新复制。
4. 展开“Plus 实时观战（实验）”：
   1. 填本机 Dota 安装目录，点“一键配置观战 GSI”，按提示完全重启本机 Dota 一次。
   2. 用账号 B（有 Dota Plus，和游戏账号互为好友）对游戏账号开始实时观战。
5. 要显示对手面板，再在教练机运行视觉扫描（新版教练端上方有“启动视觉扫描”按钮）。步骤见 `PLUS-ALERTS.md`；扫描程序在源码仓库里，不在安装包内。

“Plus 实时观战（实验）”折叠区里还有这些设置：

- **对手等级和装备**、**对手离开视野**两个开关，默认都开。
- **离开视野字幕显示**的秒数，默认 3 秒。
- 推送状态：推送了几名敌方英雄；没推送时写明原因。

状态区显示游戏端是否连着、最近一条状态是多少毫秒前收到的，以及游戏机的自身 GSI。

| 折叠区 | 内容 |
|---|---|
| Plus 实时观战（实验） | 观战 GSI 配置、观战数据与延迟、推送开关、字幕秒数、推送状态 |
| Debug | 开启 Debug 记录、打开 Debug 目录、发送测试提醒（检查游戏机能否收到字幕） |

## 游戏机

1. 解压游戏端 ZIP，运行 `DotaCoach.GameClient.exe`。
2. 粘贴配对码，点“**连接**”。连接时不再弹出画面传输确认；连上后按钮变成“断开”。
3. 第一次连接会自动写入自身 GSI 配置。提示“已写入/更新”时，完全退出并重启 Dota 一次。Steam 里 Dota 的启动选项要含 `-gamestateintegration`，状态区会显示检查结果。
4. Dota 请用“无边框窗口”。字幕、对手面板和血量数字都画在 Dota 窗口上；Dota 最小化时不显示，游戏端也暂停向教练端报到，恢复后自动继续。
5. 要看小兵血量，展开“小兵血量：本机实时显示”，点“显示小兵血量”。它和教练端连接无关，不连接也能用。

状态区有两块：连接状态；自身 GSI（英雄与游戏时间、小地图单位数、启动参数检查）。

| 折叠区 | 内容 |
|---|---|
| 小兵血量：本机实时显示 | 开关和刷新状态（帧率、识别耗时、血条数、认出兵种数） |
| 游戏内显示 | 字幕和对手面板的开关、位置、大小、颜色、透明度，预览 8 秒，恢复默认 |
| 设置：Dota 目录 | Dota 安装目录、复制启动参数 |
| Debug | 开启 Debug 记录（不存图片；对局中每秒记录小地图明细）、打开 Debug 目录 |

测试连接时开着 Dota（停在菜单也可以），在教练端 Debug 里点“发送测试提醒”。

## 相比 v0.4.2

- **游戏端**：
  - 去掉画面预览、视频状态行，以及“设置”里的画面来源、帧率、分辨率、编码器、码率和采集方式。
  - 新增“小兵血量”和“游戏内显示”两个折叠区。
- **教练端**：
  - 去掉右侧画面预览和“AI 自动教练”面板，以及“模型设置”“小地图校准”两个折叠区。
  - 不再调用云端模型，也不接受视频连接。
  - 离开视野字幕的秒数移到“Plus 实时观战（实验）”。
- **包内说明**：本文件，以及 `NO-VIDEO.md`、`CREEP-HP.md`、`PLUS-ALERTS.md`、`GAME-OVERLAY.md`、`PLUS-SPECTATOR.md`、`PLAYER-MINIMAP.md`、`DEBUG-DETAILS.md`。不再附带 `VIDEO-v040.md`。

## 验收情况

- **小兵血量**：在开发机（RTX 3090 Ti，4K）上用英雄试玩和真实地图 5v5 机器人局核对过精度和帧率影响，见 `CREEP-HP.md`；还没在游戏机上验收。
- **对手面板和离开视野**：用录下的扫描记录和观战 Debug 记录回放验证过，还没用真人 Plus 对局验收。
- **不传画面的连接**：自动化测试用真实的两端窗口、经 TLS 跑通了连接、测试字幕和对手面板；还没在两台机器、真实 Dota 窗口上跑过。
