# 高频补刀检测：4K 游戏机，2026-11-18

**真实试玩没有达到 200 检测帧/秒。** 本轮不改 Dota 的 FPS 上限、画质或显示拓扑，也不注入游戏、不采集桌面。测试机为 7950X3D / RTX 5090 D v2，Windows 活动显示路径为 3840×2160 @ 240 Hz 与 3840×2160 @ 160 Hz；Dota 窗口在 240 Hz 屏上。

| 测量 | 结果 | 边界 |
|---|---|---|
| 官方露娜试玩，游戏端 EXE 自带测量模式，第一版直接映射扫描 | 全程满足 GSI 和前台条件的三段共 15.25 秒，取得 2,366 帧，完成 2,358 帧（99.66%）；各段 **156.37 / 154.84 / 152.67 FPS**，合计 **154.62 FPS** | 非相同画面的回放。保留另外三段资格中断或为零的原始计数，不混入平均 |
| 同一局，单独读取 WGC 帧，不缩放、不识别、不画框 | 三段 5 秒分别 **153.78 / 155.98 / 159.40 FPS**；每段 WGC 新帧时间戳间隔中位数均为 **6.2499 ms** | 只测 WGC 实际交付，不是引擎渲染计数；高刷捕获接口启用成功 |
| 双缓冲最终链路，独立 4K 测试窗口、同一屏幕 | 默认设备两段各 6 秒分别识别到 **954 / 959 个严格递增的画面编号**，约 **159–160 FPS** | 画面由 320 Hz 定时器驱动更新，通过同一 WGC、GPU 缩放、扫描和判断，不是 Dota。指定显示适配器也没有突破 160；未把该改动并入产品 |
| 双缓冲最终链路，跳过 WGC，直接提供有编号的 4K GPU 图像 | 预热后 10.0002 秒完成 **2,400 帧，240.00 FPS**；逐帧验证三个可见血条编码，无重复或错序 | 包含 GPU 缩放、NV12 回读、识别与判断；不含游戏、WGC、WPF 绘制或显示 |

结论仅限于这套配置的实测窗口：检测器有 200+ FPS 的处理能力，当前窗口采集未交付 200 个不同帧/秒。6.25 ms 与 160 Hz 周期一致，但**并未证明**是第二块屏幕导致。要验证该假设，应在用户同意下临时仅启用 240 Hz 屏，与原双屏配置在同一试玩场景对照。最终双缓冲版在本轮试玩过期前没有取得新的完整实机段，不将测试窗口或合成数字充当最终版对局 FPS。

`results.json` 保存区间原始计数。复跑离屏 GPU 检测基准：`dotnet run -c Release --project desktop/DotaCoach.TwoPc.Tests -- --last-hit-gpu-bench`（Windows）；功能回归使用 `--last-hit`。本次补刀专项 22 项、双机核心套件 249 项通过。
